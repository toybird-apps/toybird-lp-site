Apply it to a real task

Start with the source of truth you already use—an email thread, meeting record, worksheet, PDF, or system screen—rather than creating another layer of notes.

Why window switching becomes costly on one screen

Copying figures from a PDF, following web instructions or applying feedback from chat all require rapid movement between a reference and a work app. The switch is brief, but returning means finding the cursor, selected cell or unfinished sentence again.

The goal is not to show more windows. It is to rank information by importance: keep the main task large and make supporting information only as large as it needs to be readable.

Choose the layout that fits the task

Choose by how often you check the reference and whether both apps need equal space.

Set up one real task step by step

  1. Choose the primary task
    Give the document, email, spreadsheet or other creation app most of the screen.
  2. Classify reference frequency
    Decide whether the reference is read once, checked every few minutes or checked every few seconds.
  3. Match the layout to the task
    Use tiling for equal work and a smaller reference view when the second app is mainly for checking.
  4. Check readability
    Size the reference so names, figures and instructions are readable without constant zooming.
  5. Remove the layout when finished
    Close references that are no longer needed instead of carrying visual clutter into the next task.

Where it saves time in everyday work

Data entry from a reference

Keep the input position while checking invoices, price lists or specifications.

Configuration from instructions

Keep browser instructions visible while changing system settings or another app.

Applying feedback

Edit the document while keeping chat or review comments in view.

Monitoring progress

Watch an upload, export or process status in a corner while continuing other work.

What to know before you use it

Pocket Screen is a Mac app for macOS 14 or later.

Some video and app rendering methods can cause the floating view to update differently or stop.

When sensitive information is visible, also check whether it appears in screen sharing or recordings.

Frequently asked questions

Can one MacBook screen still be productive?

Yes. Keep the primary task large and leave only the frequently checked reference visible to reduce switching without a second monitor.

When should I use Split View instead of a floating reference?

Use Split View when both apps are equally active. Use a floating reference when one app is primary and the other is mainly for checking.

Is this useful with an external display?

A second display gives more space. A floating reference is still useful while travelling, when you want less eye movement, or when one detail must stay above all apps.
