How to Keep a Mac App Visible in a Floating Window

Keep a PDF or another Mac app visible while you work. Allow screen capture, create a separate always-on-top reference view, and return to your main app.

Need to read a PDF while writing in Word, or keep a webpage visible while entering information in another app? Pocket Screen can create a small, always-on-top view of a supported Mac app window.

It creates a separate live reference view. It does not pin, move, or resize the original app window. Keep the original open, place its reference view beside your work, and switch to the app you want to use.

What stays on top?

The smaller Reference View stays above your workspace while the source window remains where it was. This is useful when you mainly read from one window and work in another.

The Reference View is for looking at the source. To type, scroll, or edit the source document, return to its original window. If both apps need frequent editing, give each a larger side-by-side window instead.

For this walkthrough, open a PDF in Preview or another supported app, plus a document in Word or your preferred editor. Pocket Screen requires macOS 14 or later, on Apple silicon or Intel.

1. Allow Screen Recording

  1. Open Pocket Screen. When macOS asks for screen-capture access, open System Settings.
  2. Go to Privacy & Security and the Screen Recording permission section. Its label may differ by macOS version.
  3. Enable Pocket Screen. Quit and reopen it if macOS asks you to restart the app.

This permission lets Pocket Screen capture the selected window for its local reference view. Captured window content is not sent to Toybird Labs servers. See the permission and setup guide if access is still unavailable.

2. Create a small reference view

  1. Bring the PDF or other supported source window to the front.
  2. Press Option + Command + P, the default primary shortcut, to create the first Reference View. If you changed shortcuts, use the one saved in Pocket Screen Settings.
  3. Move and resize the new view so the part you need is readable without covering your main work. Use Focus View when you want to enlarge a particular region.

Start with one source and one small view. The primary shortcut can also switch a selected Reference View to the current frontmost window, so select the source you intend before using it again.

3. Work in another app

  1. Leave the source open on the same desktop, then click your Word document or other main app.
  2. Keep typing or entering information while reading the small Reference View. Move it if it covers the line or controls you are using.
  3. When you need a different part of the source, return to its original window, make the change there, then return to your work.

The PDF has not become a Word window, and its original window has not been pinned. Pocket Screen is displaying a separate reference copy above the document you are editing.

Live, frozen, and paused views

A live Reference View reflects the supported source window. Freeze deliberately keeps one image, so later changes in the source do not appear until you unfreeze it.

Paused or Updating can appear when capture is interrupted, for example after changing Spaces. A preserved image is not a current live frame. Make the source window available again and check that updates resume before relying on a changing value.

If the view is blank or hard to read

  • Blank view: check Pocket Screen's Screen Recording permission and reopen it if required. Keep the source open and available; minimized, closed, protected, or other-Space windows can affect capture.
  • Text too small: enlarge the view or use Focus View. Keep headings and surrounding context visible.
  • Wrong source: bring the intended source to the front, select the Reference View you want to change, and use the configured primary shortcut.
  • Need to edit: use the original source window; the small reference is not a second editor.

Source-app, macOS, full-screen, and Space behavior can differ. The official support page covers setup and capture limitations.

Choose a layout and start free

Use a floating reference when you mostly work in one app and occasionally read another. Use macOS window tiling when you need room to operate both apps repeatedly. Built-in video Picture-in-Picture serves a different need from referencing a supported document or app window.

Pocket Screen Free supports up to two Reference Views in sessions of up to 10 minutes, with no expiration. Unlimited supports up to four views without the time limit. Check the current product guide for plans.
