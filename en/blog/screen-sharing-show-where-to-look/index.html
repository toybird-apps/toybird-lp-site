Apply it to a real task

Start with the source of truth you already use—an email thread, meeting record, worksheet, PDF, or system screen—rather than creating another layer of notes.

One cue cannot explain a point, an area and a window equally well

For a small button, viewers need the click location. For a settings panel or part of a table, they need the relevant region. Because the target size differs, one ring cannot solve both equally well.

Across multiple apps, viewers first need to know which window is current. Establish window-level hierarchy, then indicate the point or area inside it.

Use this sequence in your next screen share

  1. Remove unnecessary information from the screen
    Pause notifications, close unused windows and remove private information before sharing.
  2. Check the operating system pointer settings
    Adjust size and colour in macOS or Windows so the pointer does not disappear against the shared content.
  3. State the purpose before pointing
    Say what will happen, then name the location: “We will disable notifications. Look at Settings in the top right.”
  4. Use different cues for a point, an area and a window
    Use a ring for a button, a frame for a table or settings group, and active-window focus for the current app.
  5. Verify the result in the sharing preview
    Check what viewers actually receive: pointer ring, frame and dimming can look different after scaling or compression.

What to know before you use it

Use meeting annotations or a drawing tool when freehand marks, arrows or text must remain visible.

Focus Cue is macOS-only. On Windows, use the ring and temporary frame.

Pointer Cue is not a full screen-annotation suite. It focuses on pointing, framing an area and identifying the current window. Its overlays run on-device without capturing the screen or extracting text for external analysis.

Frequently asked questions

When should I use a pointer ring versus a frame?

Use the ring for one control or click point; use a frame for a table column, settings panel or group of fields.

Are meeting-app annotations enough?

They are good for persistent lines and text. For a quick cue followed by normal interaction, a keyboard-triggered ring or frame interrupts less.

When should active-window emphasis be used?

Use it in a multi-app demo to establish which app matters first, then use a ring or frame for the exact target.
