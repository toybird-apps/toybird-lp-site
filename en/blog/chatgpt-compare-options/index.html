How to Compare Options and Build a Decision Table with ChatGPT

Compare products or services with ChatGPT by defining criteria, priorities, missing data and the conditions for a recommendation.

What this guide will help you do

  • Use the same criteria for every option.
  • Explain the organisation, user and decision context.
  • Define which criteria have the highest priority.
  • Do not let missing information become an automatic low score.

Apply it to a real task

Start with the source of truth you already use—an email thread, meeting record, worksheet, PDF, or system screen—rather than creating another layer of notes.

Ready-to-use prompt

Replace the bracketed text with your situation. Remove or anonymise confidential information, and verify the final output against the source before using it.

Ready-to-use prompt
Compare the options below for our specific situation.
Situation: [organisation, users and use case]
Options: [A, B, C]
Comparison criteria: [price, support, deployment time, ease of use, etc.]
Priorities: [what matters most and why]
Missing information: mark as “Unknown”; do not treat it as a disadvantage.
Output:
1. Comparison table
2. Important trade-offs
3. Information to verify
4. Recommendation with reasons

Use only the supplied information. Separate facts from your interpretation.

Example: Comparing AI training services for a 30-person company

Most employees are new to generative AI. Continuing support and beginner-friendly delivery matter more than the lowest price.

The table should compare participant limits, delivery format, beginner support, follow-up support, implementation time and price. The recommendation should explain why support and adoption were weighted above cost, and list any missing contract or cancellation information.

Ways to adapt the prompt

The core structure stays the same, but the facts, audience and desired output should change with the task.

Put budget first

State a maximum budget and ask for the lowest-cost option that still meets mandatory requirements.

Put implementation speed first

Define the required start date and treat any unconfirmed deployment time as unknown.

Do not recommend

Request only a fact table, trade-offs and questions for vendors when the final decision must remain with a committee.

Checklist before using the result

A polished answer can still contain an incorrect fact or an unsuitable commitment. Use this checklist before sharing or sending it.

  • Every score is supported by a source or clearly labelled interpretation.
  • Missing data is shown as unknown, not zero.
  • Priorities reflect the actual decision.
  • The recommendation explains trade-offs, not only the winner.
  • Contract, security and current pricing are verified with primary sources.

Frequently asked questions

Should I ask ChatGPT to create numerical scores?

Only when the scoring rules and evidence are clear. Otherwise a qualitative table may be more honest.

How many options can I compare?

More options increase the chance of shallow analysis. Start with a manageable shortlist and consistent criteria.

Can ChatGPT research the options itself?

It can help, but current pricing and specifications should be checked against official sources and dates.
