How to Use Stage Manager Productively Without Losing Your Reference Window

Stage Manager is designed to organise work sets. Keep related apps in one group, then preserve only the one reference that must remain visible when you switch groups.

Author: Masaki IinoUpdated: August 3, 20268 min read

Use Stage Manager on Mac without repeatedly losing a PDF, webpage or chat reference. Compare same-group layouts with a persistent floating reference across work sets.

Answer in brief

Productive Stage Manager use is not about stuffing every window into one group. Separate apps that should switch together from the reference that must stay available across activities.

  • Group apps that belong to the same task
  • If the reference disappears with every group switch, Stage Manager loses some of its organisational benefit
  • Choose between same-group placement and persistent display by check frequency

How Stage Manager groups affect reference material

Apple Stage Manager centres the current app, organises recent apps at the side and lets multiple apps behave as a group. It is well suited to switching between work sets.

A reference in another group disappears when you return to the work group. Adding it to the same group solves that, but one MacBook screen can become crowded.

Choose the layout that fits the task

Choose between the same group and an independent reference based on whether the information must cross work sets.

Set up one real task step by step

  1. List the moments that trigger a window switch
    Note which reference you check, during which task, and how often.
  2. Try the built-in macOS layouts first
    If tiling or Stage Manager solves the problem, there is no reason to add another tool.
  3. Protect the main workspace first
    Keep the app where you type or edit large, and size the reference only as much as needed.
  4. Adjust readability and overlap
    Place the reference where figures and instructions are readable without covering fields or controls.
  5. Review the layout for each task
    Do not keep yesterday’s references around; show only what supports the current task.

You will feel the difference when this keeps happening

If you keep opening a reference and returning to the same task, check whether these situations sound familiar.

Start here when

  • You check a PDF, webpage or chat every few seconds or minutes
  • You work on one MacBook without an external display
  • You want the main app to stay large while support information remains visible

Built-in tools are enough when

  • The reference is read only once
  • Both apps need equal space and constant interaction
  • The task requires full-size colour or detail review

What to know before you use it

Stage Manager behaviour varies with macOS settings, recent-app visibility and the target app’s rendering method. Test important workflows on the actual Mac first.

Pocket Screen processes the selected view on your Mac and does not send window content to a developer server or external AI service. Rendering and update behaviour can vary by app and video technology.

Frequently asked questions

Can multiple apps be placed in one Stage Manager group?

Yes. Stage Manager can group multiple apps and switch them as a set.

Is keeping the reference in the same group enough?

It is enough when the reference belongs to one work group. If several groups need the same source, an independent reference avoids losing it on each switch.

Does Pocket Screen work without Stage Manager?

Yes. It also shows a selected window as a reference view in the standard desktop environment.

Can video be shown while using Stage Manager?

Some video works, including Safari-based cases, but certain rendering paths such as some Chromium video can freeze or appear black. Test the target app first.
