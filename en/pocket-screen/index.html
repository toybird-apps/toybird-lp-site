What kinds of windows can I display?

Supported Mac windows such as browsers, documents, PDFs, videos, and dashboards can be displayed as a floating window

Can I create multiple Reference Views from the same window?

Yes. Based on user feedback, v2.0 added support for creating multiple Reference Views from the same source window.

Does Pocket Screen create a separate live view of the original window?

Yes. Pocket Screen creates a separate live view of the selected supported window. The original app window stays in place while the smaller view remains visible above your workspace.

How is Pocket Screen different from pinning a window or built-in Picture-in-Picture?

Pinning keeps the original window above other apps. Pocket Screen instead creates a separate, resizable live view of a selected supported app window. macOS built-in Picture-in-Picture is mainly for video, while Pocket Screen can display supported browsers, documents, PDFs, dashboards, chats, videos, and other app windows.

Can I use my own keyboard shortcuts?

Yes. Choose Custom in Settings to set shortcuts for creating or switching a view, showing or hiding all views, adding a view, and closing the selected view. If you use Stream Deck Mobile, keep the profile’s key combinations aligned with those settings.

Is window content sent outside my Mac?

No. The selected window is displayed locally on your Mac and is not sent to Toybird Labs servers or external AI services

What is the difference between Free and Unlimited?

Start with Free, then choose Unlimited when you need longer sessions, more references, or higher quality. The exact differences are summarized in the pricing section above

Can I keep Pocket Screen out of screen sharing or recordings?

On macOS 26 or later, Pocket Screen can be excluded from supported screenshots, screen recordings, and screen sharing

Which Macs are supported?

Pocket Screen supports macOS 14 or later on both Apple silicon and Intel Macs
