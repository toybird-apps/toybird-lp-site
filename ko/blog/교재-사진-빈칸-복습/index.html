교재 사진과 PDF로 복습하기｜원래 페이지에서 Auto까지

필기와 교재를 새 카드로 옮기지 않고 가져옵니다. 그림과 설명을 남긴 채 Auto로 답을 떠올리고, 추천 복습으로 저장한 자료에 다시 돌아가는 방법입니다.

새 프린트를 받을 때마다 암기 카드를 다시 만들 필요는 없습니다. AI Study Sheet에 사진이나 PDF를 가져와 마스크를 확인하고 원래 페이지에서 복습할 수 있습니다. 아래 예시는 무엇을 가리고 어떤 설명과 화살표를 남겨야 하는지 보여 줍니다.

예시 자료는 사용 방법을 설명하기 위한 것으로, 실제 학습 성과를 측정한 기록이 아닙니다.

확인할 수 있는 원자료

번호 용어 설명
R1 증발 액체 상태의 물이 수증기로 바뀝니다.
R2 응결 수증기가 액체 물로 바뀝니다. 작은 물방울이 구름을 이룰 수 있습니다.
R3 강수 비나 눈 등의 형태로 물이 구름에서 떨어집니다.

상태 변화와 떨어지는 현상을 구분하는 것이 목표입니다. 응결과 강수를 바꿔 답했다면 정답 단어만 다시 보는 대신 R2와 R3를 비교합니다. 근거: USGS 응결 설명, USGS 강수 설명.

질문은 남기고 답만 가립니다

남길 내용 가릴 답 확인 목적
액체 물이 수증기로 바뀜 증발 상태 변화의 이름
수증기가 액체 물로 바뀜 응결 반대 과정과 구별
물이 구름에서 비나 눈으로 떨어짐 강수 물방울 생성과 떨어짐 구별

용어와 설명을 모두 가리면 질문이 사라집니다. 제목에 같은 단어가 남아 있으면 기억이 아니라 읽기로 맞힐 수 있습니다. 그림 설명과 여백까지 확인하세요.

Auto에서 답이 나오기 전에 떠올리기

Auto에서는 강조된 답이 3초 뒤에 표시됩니다. 보이는 문맥을 읽고 먼저 답을 떠올린 다음 원문과 비교합니다. 답을 열기 위해 반복해서 누르는 동작을 줄일 수 있습니다.

v4.1에서는 동시에 출제할 마스크 수를 자동 조정하거나 1~5개로 고정할 수 있습니다. 자동 조정은 기본 3개이며, 페이지 끝이나 서로 멀리 떨어진 영역에서는 1~2개가 됩니다. 복잡한 표는 수를 줄이거나 잠시 멈추고 읽으세요. 변경한 설정은 새 학습부터 적용되며, 이어 하기는 시작 당시 설정을 유지합니다.

가져오기, 마스크 확인, 내 교재로 학습 시작

복습할 페이지를 사진이나 PDF로 추가합니다. 일반 모드에서는 제안된 마스크를 확인하고 조정할 수 있습니다. 표의 제목, 조건, 그림의 화살표 등 답을 이해하는 데 필요한 부분을 남겨 둡니다. 인식이 잘못된 곳은 반복해서 학습하기 전에 수정합니다.

첫 학습을 완료하면 무료 저장 한도가 10페이지로 늘어납니다. Auto도 무료 범위에서 이용해 볼 수 있습니다. 다른 단원과 과목의 자료를 계속 저장하려면 일회성 구매로 앱의 페이지 수 제한을 해제할 수 있습니다.

기억한 정도를 평가하고 필요한 설명으로 돌아가기

학습 후에는 얼마나 기억했는지 직접 평가합니다. 자동 채점 결과가 아닙니다. 용어는 떠올랐지만 그림을 설명하지 못했다면 원래 페이지의 설명을 다시 읽습니다.

추천 복습은 자기평가, 학습 활동, 복습 시점 등을 이용해 저장한 교재를 선택합니다. 알림을 허용했고 복습할 자료가 있으면 알림에서 Auto로 들어갈 수 있습니다.

내신·수능·자격증｜내 교재를 추가하고 계속 복습하는 흐름공부한 사진과 PDF를 차례로 추가하고, 짧은 시간에는 Auto와 추천 복습을 사용합니다. 용어 확인을 원래 교재의 설명과 문제 풀이로 연결합니다.

사진과 PDF를 원래 모습으로 사용하세요. Auto로 시작하고 추천 복습으로 저장한 교재에 다시 돌아갈 수 있습니다.
