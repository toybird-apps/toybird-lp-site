블로그 소개

제품보다 먼저 일과 학습 방식을 생각합니다

Toybird Labs Blog는 일과 공부에서 자주 겪는 불편에서 출발합니다. 먼저 흐름을 바꾸는 방법을 제안하고, 제품은 마지막에 그 방법을 구현하는 한 가지 수단으로 소개합니다.

  • AI Work Brief로 AI에게 넘길 일을 정리하기
  • 기존 교재에 Recall Layer를 더해 답하며 복습하기
  • Reference View로 필요한 정보를 시야에 남기기
  • Shared Attention으로 화면 공유에서 보는 위치 맞추기

AI Work Brief

프롬프트보다 먼저 일을 정의하기

작업, 원자료, 조건, 미확정 사항, 완성 형태를 먼저 정리합니다.

AI Work Brief

ChatGPT 업무 활용 | 프롬프트 전에 AI Work Brief 만들기

프롬프트 문구를 고민하기 전에 일을 먼저 정리합니다. 작업, 원자료, 목적과 독자, 조건, 미확정 사항, 완성 형태를 AI Work Brief로 묶어 AI에게 넘길 수 있는 상태를 만듭니다.

AI Work Brief

ChatGPT로 견적 비교표 만들기: 인원과 필수 조건을 먼저 맞추기

회당 요금, 전체 요금, 인당 요금은 숫자만 나란히 놓아서는 비교할 수 없습니다. 같은 서비스를 제공하는 총액으로 계산한 뒤 필수 조건을 확인해야 합니다.

AI Work Brief

ChatGPT로 고객 답장 쓰기: 확인된 사실과 약속할 수 있는 범위부터

고객은 회의 전에 자료가 필요하지만 기술팀은 아직 장애 원인을 모릅니다. 이때 필요한 것은 복구를 장담하는 답장이 아니라, 현재 상황과 다음 연락을 분명히 알리는 첫 답장입니다.

AI Work Brief

회의 메모를 할 일로 바꾸기: 담당자와 문의 대상을 바꾸지 않는 방법

메모에 이름이 있다고 그 사람이 담당자는 아닙니다. “다나카에게 물어보기”는 사토의 할 일일 수 있습니다. 결정, 제안, 취소, 미배정 사항을 분리한 뒤 후속 메일을 만드세요.

Recall Layer

이미 있는 교재를 ‘답하는 교재’로 바꾸기

원래 페이지를 유지한 채 가리기, 답하기, 확인하기를 더합니다.

Recall Layer

교재를 다시 만들지 않고 복습하기 | Recall Layer

이미 있는 교재를 다시 카드로 옮기지 않습니다. 원래 페이지 위에 가리기 → 답하기 → 확인하기를 더하는 Recall Layer로 읽는 자료를 답하는 자료로 바꿉니다.

Recall Layer

내신·수능·자격증 복습을 내 교재로 구성하기: 일주일 운영 예시

촬영한 자료가 많아져도 어떤 페이지를 왜 볼지 정하지 않으면 복습 계획이 되지 않습니다. 구체적인 오답을 원설명과 연결하고 실제 문제를 푸는 시간을 남겨 보세요.

Reference View

필요한 정보를 작업 중에 사라지지 않게 하기

주 작업과 반복해서 확인하는 작은 참고 정보를 분리합니다.

Reference View

Mac 화면 하나에서 필요한 정보를 놓치지 않는 방법 | Reference View

스크롤하거나 창을 바꿀 때 숫자·조건·문단이 사라진다면, 자주 확인하는 정보만 작은 Reference View로 남기고 주 작업은 크게 유지합니다.

Shared Attention

화면 공유에서 보는 위치까지 공유하기

말, 대상, 조작, 결과를 같은 흐름으로 맞춥니다.

Shared Attention

화면 공유에서 어디를 봐야 하는지 전달하기 | Shared Attention

발표자는 어디를 보는지 알고 있지만 시청자는 모릅니다. Shared Attention은 말, 볼 위치, 조작, 결과를 같은 흐름으로 맞춰 모두가 같은 지점을 따라오게 합니다.
