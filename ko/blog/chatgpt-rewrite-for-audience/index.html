생성형 AI와 업무 생산성

ChatGPT로 고객, 경영진, 사내용 문장을 대상에 맞게 바꾸는 방법

사실은 유지하고 설명 방식, 용어, 강조점을 읽는 사람에 맞게 바꿉니다.

2026년 8월 3일9 분작성자 Masaki Iino

이 글에서는 ChatGPT를 업무에 활용하는 실용적인 방법을 설명합니다. 마법 같은 프롬프트를 외우는 것이 아니라, 작업에 필요한 배경과 조건, 출력 형식을 명확히 전달하는 것이 핵심입니다.

예시 요청문을 복사한 뒤 대괄호 안의 내용을 자신의 상황에 맞게 바꾸고, 실제 업무에 사용하기 전에 결과를 확인하세요.

핵심 요약

  • 새로운 대상이 이미 아는 내용과 해야 할 행동을 정의합니다.
  • 바꾸면 안 되는 사실, 용어, 제한 사항을 목록으로 적습니다.
  • 문체, 길이, 용어 수준, 다음 행동을 지정합니다.
  • 확인 없이 바꾸기 어려운 정보는 따로 표시하도록 요청합니다.
  • 수정본과 원문을 비교해 의미가 달라지지 않았는지 확인합니다.

“고객에게 맞게 바꿔 주세요”는 표현뿐 아니라 사실도 바꿀 수 있습니다

짧은 지시만으로 원하는 결과가 나오지 않는 이유

이 글을 고객용으로 바꿔 주세요.

더 안정적인 접근 방법

고객의 사전 지식, 목적, 문체, 다음 행동과 반드시 유지할 사실, 숫자, 제품 한계를 함께 지정합니다.

함께 제공할 정보

  • 원문과 확인된 사실
  • 새로운 대상과 사전 지식
  • 수정한 글의 목적
  • 문체, 길이, 용어, 구조
  • 그대로 유지하거나 설명해야 할 세부 내용

재사용 가능한 요청문 템플릿

대괄호 안의 내용을 자신의 상황으로 바꾸세요. 누락된 사실을 추측하지 말고 확인이 필요한 항목을 따로 정리하도록 요청하는 것이 좋습니다.

재사용 가능한 요청문 템플릿
## 작업
아래 원문을 [대상]에 맞게 다시 작성해 주세요.

## 목적
읽는 사람이 [핵심 내용]을 이해하고 [다음 행동]할 수 있어야 합니다.

## 원문
[원문 붙여 넣기]

## 대상 조건
- 사전 지식: [초보자 / 전문가 / 경영진 / 고객]
- 문체: [격식 / 친근함 / 간결함]
- 목표 길이: [길이]
- 설명하거나 피할 용어: [목록]

## 그대로 유지할 내용
- [사실, 숫자, 제품명, 법적 문구, 제한 사항]

## 조건
- 원문에 없는 효과, 주장, 약속을 추가하지 마세요.
- 원문이 모호하면 사실로 바꾸지 말고 확인할 항목으로 적으세요.
- 의미는 유지하면서 순서와 표현을 대상에 맞게 조정하세요.

예시: 기술 안내를 처음 사용하는 고객용으로 바꾸기

원문은 개발팀을 대상으로 구현 내용을 설명합니다. 고객은 기술 용어 없이 실제 효과, 필요 조건, 알려진 제한을 이해해야 합니다.

실전 예시
이 릴리스 안내를 제품을 처음 사용하는 고객용으로 바꿔 주세요. 확인된 사용자 효과를 먼저 설명하고 쉬운 표현을 사용하세요. 지원 운영체제와 알려진 제한은 그대로 유지하세요. 성능 효과를 임의로 추가하지 말고 마지막에 명확한 다음 행동을 넣으세요.

실전 예시

이번 업데이트로 [확인된 사용자 효과]를 더 쉽게 이용할 수 있습니다. [확인된 운영체제]에서 사용할 수 있으며, 사용 전 [확인된 제한]을 확인하세요. 시작하려면 [확인된 메뉴]를 열고 안내 단계를 진행하세요.

결과를 사용하기 전 확인 사항

결과는 초안으로 활용하세요. 이름, 날짜, 금액, 약속 내용, 회사 정책을 확인한 뒤 전송하거나 결정에 사용해야 합니다.

  • 중요한 사실과 제한이 모두 유지되었습니다.
  • 새로운 대상이 내부 전문 용어 없이 이해할 수 있습니다.
  • 문체가 대상에 맞고 지나치게 홍보성이나 모호함이 없습니다.
  • 다음 행동이 실제로 가능한 내용입니다.
  • 근거 없는 효과, 비교, 약속이 추가되지 않았습니다.
회사 정책에서 허용하지 않는 개인정보, 고객 기밀, 계약 내용, 미공개 사내 정보를 입력하지 마세요. 필요한 경우 이름과 수치를 예시 정보로 바꾸세요.

자주 묻는 질문

대상별로 다시 쓰는 것과 요약은 같은가요?

다릅니다. 다시 쓰기는 설명 방식을 바꾸고, 요약은 정보량도 줄입니다. 두 작업을 함께 요청할 때는 유지할 사실을 명시하세요.

중요한 기술 용어는 어떻게 유지하나요?

“그대로 유지할 내용”에 적고 용어를 삭제하는 대신 쉬운 설명을 옆에 추가하도록 요청합니다.

여러 대상용 버전을 한 번에 만들 수 있나요?

가능합니다. 대상별로 별도 버전을 만들고 각각 목적과 최대 길이를 지정하세요.

업무 목적에 맞는 AI 요청문을 단계별로 만들기

같은 원문으로 대상별 요청문 만들기

Prompt Ready의 “다른 대상에 맞게 다시 쓰기”에서 대상, 문체, 출력 언어, 미확인 정보, 형식을 선택해 반복 사용 가능한 요청문을 만들 수 있습니다.

Prompt Ready는 앱 화면과 AI 요청문 생성 모두 한국어를 지원합니다.

Prompt Ready는 ChatGPT, Gemini, Claude 등에서 사용할 구조화된 요청문을 만드는 Windows 및 macOS 앱입니다. 업무를 선택하고 원문과 조건을 입력한 뒤 바로 붙여 넣을 수 있는 요청문을 복사할 수 있습니다.

Prompt Ready는 입력한 내용을 기기 안에서 처리하며 외부 AI 서비스나 개발자 서버로 자동 전송하지 않습니다. 생성한 요청문을 AI 서비스에 붙여 넣은 뒤에는 해당 서비스의 데이터 정책이 적용됩니다.

함께 읽을 글

관련 가이드고객 이메일에 답변하기고객의 원문, 확인된 사실, 미확인 정보, 다음 조치를 바탕으로 정확한 고객 지원 이메일을 만드는 ChatGPT 프롬프트와 확인 사항을 소개합니다.관련 가이드의도와 다른 답변 수정하기ChatGPT 답변이 너무 길거나 일반적이고, 대상이 다르거나 사실과 추측이 섞이는 이유를 확인하고 구체적인 후속 지시로 수정하는 방법을 설명합니다.관련 가이드업무에서 ChatGPT 활용하기이메일, 회의, 요약, 비교, 조사, 영업 연습 등 업무에서 ChatGPT를 더 정확하게 활용하기 위한 5가지 원칙과 10가지 실전 예시를 소개합니다.

확인된 사실이 아니라 설명 방식을 대상에 맞게 바꾸세요

좋은 대상별 문장은 용어, 순서, 강조점을 바꿔 읽는 사람이 행동할 수 있게 합니다. 제품 한계, 수치, 의무 사항은 조용히 변경되어서는 안 됩니다.
