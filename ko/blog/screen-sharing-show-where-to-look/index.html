화면 공유 설명을 따라오기 쉽게 만들기: 30초 시연 대본

포인터가 움직이는 것만으로는 버튼의 의미가 전달되지 않습니다. 말, 대상, 조작, 결과를 맞춰 시청자가 무엇이 바뀌었는지 추측하지 않게 해 보세요.

  5. 다음 시연에 적용합니다

가상 연습 화면에서 “즉시 알림”과 “주간 요약”은 모두 켜져 있습니다. 즉시 알림만 끄는 것이 목표입니다. 시간 구간은 연습용 기준이며 최적 길이를 실측한 결과가 아닙니다.

클릭 전에 결과를 먼저 말합니다

핵심은 “여기를 눌렀다”가 아니라 “즉시 알림은 꺼지고 주간 요약은 유지된다”입니다.

시간 말할 내용 조작 강조
0~5초 즉시 알림을 끄고 주간 요약은 남기겠습니다 두 설정을 보이게 유지 추가 표시 없음
5~10초 이 부분이 즉시 알림 설정입니다 이름과 스위치에 포인터 배치 잠깐 포인터 강조
10~16초 두 설정은 서로 별개입니다 두 행을 함께 설명 필요하면 범위 강조
16~22초 이 설정만 끄겠습니다 첫 스위치 한 번 클릭 움직임을 적게 하고 동작 노출
22~30초 즉시는 꺼졌고 주간은 켜져 있습니다 최종 상태에서 잠깐 멈춤 새 효과로 결과를 가리지 않음

글 안의 연습

설명용 연습이며 앱 실행 화면이 아닙니다.

한 점과 관계를 다른 방식으로 보여 줍니다

포인터는 어떤 버튼인지, 범위는 어떤 행들이 설명에 포함되는지 알려 줍니다. 읽을 수 있는 글자와 목적 설명을 대신하지는 못합니다. 설정 하나를 말하며 화면 전체를 강조하면 대상이 오히려 흐려집니다.

Pointer Cue는 Mac에서 잠깐의 포인터·범위 강조를 더할 수 있습니다. 설치된 버전에 설정된 제스처를 사용하세요. 뒤에 다시 볼 화살표를 남겨야 한다면 그리기 도구가 다른 필요를 해결합니다.

조작 후 상태를 다시 확인해 줍니다

두 설정의 최종 상태를 말하고 화면을 잠깐 유지하세요. “보시다시피”보다 무엇이 달라졌는지 구체적입니다. 추가 강조 없이 한 번, 포인터나 범위를 더해 한 번 연습하고 대상과 결과를 찾을 수 있는지 비교하세요. 효과의 개수를 늘리는 것이 목적은 아닙니다.

시청자가 받는 화면도 확인합니다

실제 원격 시연에서는 무해한 자료로 참여자 화면을 확인합니다. 작은 글자나 가는 선은 캡처와 전송 후 다르게 보일 수 있습니다. 로컬 제품 영상이 수신 측 화질을 검증한 결과는 아닙니다.

웹사이트를 조작하는 제품 영상은 강조 원리의 예시이며 이 가상 설정 화면의 실행 기록은 아닙니다. 개발 중 영상 역시 공개 버전의 기능이나 제공 조건을 자동으로 증명하지 않습니다.

다음 시연에 적용합니다

기밀 없는 실제 작업 하나를 정하고 전후 상태를 적습니다. 강조가 정보를 더하는 위치 하나를 고른 뒤 변경 후 멈추는 구간을 연습하세요. Pointer Cue는 잠깐의 표식이 말에 도움을 줄 때 사용하고, 결과를 볼 때는 조용히 두어도 됩니다.
