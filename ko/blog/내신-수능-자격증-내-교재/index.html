내신·수능·자격증｜내 교재를 추가하고 계속 복습하는 흐름

공부한 사진과 PDF를 차례로 추가하고, 짧은 시간에는 Auto와 추천 복습을 사용합니다. 용어 확인을 원래 교재의 설명과 문제 풀이로 연결합니다.

내신·수능·자격증 공부를 이어 가면 교재도 계속 늘어납니다. 이미 공부한 사진과 PDF를 AI Study Sheet에 추가하고, 추천 복습으로 저장한 자료에 다시 돌아갈 수 있습니다. 계산과 긴 서술형 답안은 원래 문제 형식으로 연습하는 시간도 남깁니다.

아래 페이지들은 교재의 쓰임을 구분하기 위한 예시이며, 반드시 따라야 하는 일주일 일정은 아닙니다.

페이지마다 역할을 다르게 줍니다

페이지 내용 사용하는 방법
P1 용어 세 개의 정의 용어 회상
P2 과정 그림 화살표와 관계 설명
P3 비슷한 개념 비교표 차이 말하기
P4 연습 문제 원래 형식으로 풀이
P5 해설 틀린 이유 찾기
P6 P1의 중복 사본 별도 복습으로 늘리지 않음

내신이나 수능 자료의 해석 문제, 자격증의 계산·사례 문제는 단어를 가리는 작업만으로 바꾸지 않습니다. 실제 수업과 시험에서 요구하는 과제를 기준으로 자료의 역할을 정합니다.

전체를 다시 정리하지 않고 교재 추가하기

오늘은 용어 표, 내일은 그림, 다음에는 다른 단원의 PDF를 추가합니다. 과목과 단원을 알 수 있는 짧은 이름이면 원본을 찾는 데 도움이 됩니다. 특정 범위를 보고 싶을 때는 폴더와 검색을 이용합니다.

매번 모든 페이지의 순서를 새로 정할 필요는 없습니다. 평소에는 추천 복습으로 시작하고, 특정 오답을 확인할 때는 해당 설명이 있는 교재를 직접 선택합니다.

오늘 가능한 분량으로 다시 시작하기

추천 복습은 자기평가, 학습 활동, 복습 시점 등을 바탕으로 저장한 자료를 고릅니다. 1~10페이지 중에서 선택할 수 있고 기본값은 3페이지입니다. 3·5·10분의 예상 시간으로 분량을 고를 수도 있습니다.

예상 시간은 시작할 때 페이지를 선택하는 기준이며, 시간이 지나면 학습을 강제로 종료하는 제한이 아닙니다. 하루를 쉬었더라도 오늘 가능한 양으로 재개합니다. 알림을 허용하고 대상 자료가 있으면 알림에서 Auto를 시작할 수 있습니다. 원래 문제를 풀 시간도 함께 확보하세요.

서로 다른 오답에 같은 처방을 쓰지 않습니다

E1은 P1 용어를 잊은 경우, E2는 P2 화살표 방향을 잘못 설명한 경우입니다. E1은 용어 질문으로 확인할 수 있지만 E2는 그림의 흐름을 말해야 합니다. 가린 이름을 열어 보는 것만으로 관계를 이해했는지 알 수 없습니다.

3일째 공부를 못했다면 4일째 모든 양을 두 배로 늘리지 않습니다. 실제 문제 풀이 한 번은 남기고, 그것을 가장 방해하는 오답 두 개부터 돌아봅니다. 이미 확실한 단어 일부는 나중으로 옮겨 계획을 실행 가능하게 유지합니다.

여러 교재로 Auto와 다음 복습까지 경험하기

페이지의 마스크를 확인하고 Auto를 시작하면 3초 뒤 답이 나옵니다. v4.1의 자동 조정이나 고정 1~5개를 선택하고, 긴 조건이나 그림을 읽어야 할 때는 잠시 멈춥니다.

첫 학습 완료 후 무료로 10페이지까지 저장할 수 있습니다. 여러 자료를 추가해 다음 복습까지 사용해 보고, 교재가 더 필요해지면 일회성 구매로 페이지 수 제한을 해제할 수 있습니다. 자기평가는 기억한 정도를 기록하며, 서술형 답안은 원래 해설로 확인합니다.

다음에 읽기

교재 사진과 PDF로 복습하기｜원래 페이지에서 Auto까지필기와 교재를 새 카드로 옮기지 않고 가져옵니다. 그림과 설명을 남긴 채 Auto로 답을 떠올리고, 추천 복습으로 저장한 자료에 다시 돌아가는 방법입니다.
