내신·수능·자격증 복습을 내 교재로 구성하기: 일주일 운영 예시

촬영한 자료가 많아져도 어떤 페이지를 왜 볼지 정하지 않으면 복습 계획이 되지 않습니다. 구체적인 오답을 원설명과 연결하고 실제 문제를 푸는 시간을 남겨 보세요.

여섯 페이지와 일주일 계획은 가상 예시입니다. 학교 범위와 시험 요구에 맞춰 바꾸는 출발점이지 공식 일정이나 모든 학습자에게 최적인 간격이 아닙니다.

페이지마다 역할을 다르게 줍니다

페이지 내용 사용하는 방법
P1 용어 세 개의 정의 용어 회상
P2 과정 그림 화살표와 관계 설명
P3 비슷한 개념 비교표 차이 말하기
P4 연습 문제 원래 형식으로 풀이
P5 해설 틀린 이유 찾기
P6 P1의 중복 사본 별도 복습으로 늘리지 않음

내신이나 수능 자료의 해석 문제, 자격증의 계산·사례 문제는 단어를 가리는 작업만으로 바꾸지 않습니다. 실제 수업과 시험에서 요구하는 과제를 기준으로 자료의 역할을 정합니다.

이름이 오답의 원인으로 연결되게 합니다

“3단원—과정—P2”는 “사진48”보다 찾기 쉽습니다. 제목이나 메모에 원쪽 번호와 주제를 남깁니다. 폴더는 과목을 묶고, 페이지 식별자는 오답 후 돌아갈 정확한 위치를 맡습니다.

화면은 앱 라이브러리의 참고 이미지입니다. 가상의 P1~P6 자료 묶음을 화면 안에 합성한 것이 아닙니다.

첫 일주일을 이렇게 운영해 봅니다

날 작업 남길 기록
1일 P1~P3을 읽고 명확한 문제 몇 개 준비 원자료 번호와 불명확한 마스크
2일 P1에 답하고 P2를 설명 총 오답 수보다 구체적인 혼동
3일 P3의 개념 비교, 전날 오답 재확인 왜 다른지 설명
4일 P4를 원래 형식으로 풀이 오답을 P1~P3 또는 P5와 연결
5일 연결된 설명만 다시 확인 수정된 설명 한 문장
6일 같은 약점의 다른 문제 풀이 다른 문항에도 적용하는지
7일 남은 미해결 항목 점검 다음 주의 작은 목표 목록

서로 다른 오답에 같은 처방을 쓰지 않습니다

E1은 P1 용어를 잊은 경우, E2는 P2 화살표 방향을 잘못 설명한 경우입니다. E1은 용어 질문으로 확인할 수 있지만 E2는 그림의 흐름을 말해야 합니다. 가린 이름을 열어 보는 것만으로 관계를 이해했는지 알 수 없습니다.

3일째 공부를 못했다면 4일째 모든 양을 두 배로 늘리지 않습니다. 실제 문제 풀이 한 번은 남기고, 그것을 가장 방해하는 오답 두 개부터 돌아봅니다. 이미 확실한 단어 일부는 나중으로 옮겨 계획을 실행 가능하게 유지합니다.

반복 부분을 AI Study Sheet에서 정리합니다

선택한 사진·PDF를 가져와 마스크를 확인하고 폴더나 검색으로 학습 범위를 고릅니다. 순서대로는 과정을 따라가는 데, 무작위는 페이지 순서에 의존하지 않는 확인에, 약점 우선은 기록된 어려움을 다시 보는 데 사용합니다. 끝낼 수 있는 세션 크기를 선택하세요.

앱 결과가 과목 전체의 숙달을 보증하지는 않습니다. 서술, 계산, 새로운 문제를 푸는 과정도 필요합니다. 일주일 뒤에는 어떤 페이지를 어떤 오답 때문에 보며 무엇으로 이해를 확인할지 설명할 수 있어야 합니다.
