生成AI・仕事効率化

ChatGPTに不足情報を質問してもらう方法｜質問させるプロンプト例

目的や条件をすべて自分で整理できなくても、回答を作る前にChatGPTから確認してもらえます。質問の数や順番を指定する実践的な例を紹介します。

著者：飯野 昌紀公開：2026年8月3日読了目安：約8分

指示を書き始めたものの、何を伝えればよいか自分でも分からない。そんなときは、先にChatGPTから聞いてもらえます。

質問の数や順番を指定し、必要な条件を対話でそろえてから回答へ進む方法を紹介します。

この記事でできるようになること

  • 回答に必要な情報が不足している場合は、推測せず先に質問させる
  • 質問数を「一度に一つ」または「最大3つ」と指定する
  • まだ回答を作らないように明記する
  • 自分が答えやすいように、選択肢を付けてもらう方法もある
  • 機密情報を聞かれた場合は、社内ルールに従って回答範囲を判断する

何を伝えればよいか分からないときは、先に聞いてもらう

プロンプトを作ろうとしても、何を書けばよいか自分でも分からないことがあります。そのまま回答を作らせると、ChatGPTが不足部分を推測し、意図と違う結果になる場合があります。

  • 依頼の目的はあるが、必要な条件が分からない
  • 顧客向けの文章で、確認すべき事実を漏らしたくない
  • 複数の選択肢があり、何を優先するか整理できていない
  • 初めて行う作業で、入力すべき情報を知らない
  • 回答を作る前に、曖昧な部分だけを明らかにしたい

このような場合は、回答を急いで作らせるのではなく、先に確認質問を出すように指示します。

まずは、この1文を追加する

基本の一文
回答を作るために必要な情報が不足している場合は、推測して回答せず、先に最大3つまで質問してください。

質問を一度に多く出してほしくない場合は、次のようにします。

一度に一つずつ質問させる
この作業に必要な情報を、一度に一つずつ質問してください。
私が回答するまで次の質問へ進まないでください。
必要な情報がそろうまでは、完成した回答を作らないでください。

用途に合わせて使える4つの質問パターン

1．一度に一つずつ質問する

考えながら条件をそろえたいときに使えます。質問が多くても、一つずつ整理できます。

2．重要な質問を最大3つに絞る

短時間で進めたい場合に使います。

最大3つに絞る
回答の品質に最も影響する不足情報だけを、重要度順に最大3つ質問してください。
細かな確認は後回しにし、回答を作る前に必須の情報を優先してください。

3．選択肢を付けてもらう

専門用語が分からない場合や、選べる条件を知らない場合に役立ちます。

選択式の質問
不足情報を質問するときは、可能であれば2〜4個の選択肢と、それぞれの違いを短く示してください。
選択肢に当てはまらない場合は、自由に回答できる形にしてください。

4．事実と希望を分けて質問する

確定している条件と、好みや判断基準を混ぜたくない場合に使います。

事実と希望を分ける
確認質問を、次の2種類に分けてください。
1. 回答に必要な事実（日程、対象者、予算など）
2. 私の希望や優先順位（文体、重視する条件など）
各質問がどちらに当たるか分かるようにしてください。

例：顧客向けの案内メールを作る前に質問してもらう

「新機能の案内メールを作って」とだけ依頼すると、読み手、公開日、伝えるメリット、顧客に求める行動などが不足しています。

質問から始める依頼
新機能を顧客へ案内するメールを作りたいです。
完成したメールはまだ作らず、必要な情報を一度に一つずつ質問してください。
読み手、案内の目的、公開日、顧客に伝えるメリット、顧客に取ってほしい行動が明確になるまで確認してください。
私の回答に曖昧な点があれば、追加で質問してください。

会話の進み方のイメージ

ChatGPT：この案内を送る相手は、すべての顧客ですか。それとも特定のプランや利用状況の顧客ですか。

利用者：有料プランを利用している管理者です。

ChatGPT：新機能によって管理者ができるようになることを、最も重要なものから教えてください。

利用者：利用状況を週次レポートで確認できます。

ChatGPT：顧客には、メールを読んだ後に設定を変更してほしいですか。それとも機能を知ってもらうだけでよいですか。

このように質問へ答えながら条件を整理すると、最初から長いプロンプトを自分で作る必要がありません。

条件がそろったら、回答へ進む

  1. 回答前に条件を一覧化する
    ChatGPTが理解した目的、読み手、条件を箇条書きで確認します。
  2. 不足や誤解を修正する
    完成品を作る前なら、前提を直しやすくなります。
  3. 最初は構成だけを作る
    複雑な文書なら、見出しや含める内容を先に確認します。
  4. 本文を作り、必要な部分だけ直す
    長さ、文体、順序などを追加指示で調整します。
条件を確認してから作成する
必要な情報がそろったら、すぐに本文を作らず、まず次の項目を一覧で確認してください。
- 目的
- 読み手
- 使用する事実
- 守る条件
- 回答形式
私が「この内容で進めてください」と回答した後に、完成した文章を作ってください。

すぐ回答してもらう方が早い場面

条件がすでに明確な単純作業

誤字修正や形式変換など、必要な情報がそろっている作業では、そのまま依頼した方が早い場合があります。

緊急で仮案が必要な場合

質問を待つ時間がない場合は、「不足情報は仮定せず、空欄または確認事項として残した仮案を作ってください」と伝えます。

機密情報を聞かれる可能性がある場合

質問されたからといって、すべての情報を入力する必要はありません。会社のルールに従い、回答できない情報は仮名や一般化した内容へ置き換えます。

よくある質問

ChatGPTは自動的に不足情報を質問してくれますか？

質問する場合もありますが、必ず質問するとは限りません。推測してほしくない場合は、「回答を作らず、先に質問してください」と明示します。

質問が多すぎる場合はどうすればよいですか？

「回答の品質に最も影響する質問を最大3つに絞ってください」または「一度に一つずつ質問してください」と制限します。

質問に全部答えられない場合はどうなりますか？

分からない項目は「未確認」と伝え、その情報がなくても作れる仮案と、決定前に確認すべき点を分けてもらいます。

ChatGPTに質問だけを作ってもらうこともできますか？

できます。資料や計画を渡し、「回答は作らず、不足情報と確認すべき質問だけを作ってください」と依頼します。

Prompt Ready

不足情報を確認する依頼文を、用途から作る

この記事のテンプレートはそのまま使えます。ただ、相手や目的が変わるたびに、読み手・条件・出力形式を整理し直すのは手間です。

Prompt Readyなら、用途を選び、元の文章と必要な条件を入力するだけで、ChatGPT、Gemini、Claudeへ貼り付ける依頼文を作れます。

Prompt Readyが入力した文章を自動的に外部のAIや開発者のサーバーへ送信することはありません。文章と依頼文は端末内で処理されます。ただし、作成した依頼文や元の文章を生成AIへ貼り付けた後は、利用先サービスの条件が適用されます。
