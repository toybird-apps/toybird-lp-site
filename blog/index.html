このブログについて

製品より先に、仕事と学習のやり方を考える

Toybird Labs Blogは、製品機能を並べるのではなく、日々の仕事や学習で起きる「あるある」から出発します。既存の仕事・情報・教材を作り直さず、使い方を変える4つの視点を、具体的なケースで掘り下げます。

  • AIへ仕事を渡せる形にする「AI Work Brief」
  • 今ある教材に「答える」を足す「Recall Layer」
  • 必要な情報を作業中に消さない「Reference View」
  • 画面共有で見る場所まで合わせる「Shared Attention」

AI Work Brief

プロンプトを書く前に、仕事をAIへ渡せる形にする

返信、会議、比較、商談練習。言い回しより先に、作業・元資料・条件・未確定事項・完成形を整理します。

AI Work Brief

ChatGPTを仕事で使う｜プロンプトより先に作る「AI Work Brief」

ChatGPTを開いてから依頼文を考えるのではなく、仕事そのものをAIへ渡せる形に整理します。

AI Work Brief

ChatGPTに先に質問してもらう｜曖昧な仕事の依頼を、着手できる条件へ変える

引き継ぎ資料の作成を例に、AIへ先に確認質問をさせる方法を解説。最大3問で条件を整理し、未定事項を残したまま初稿へ進めます。

AI Work Brief

ChatGPTで比較表を作る｜3社の見積もりを同じ条件に揃え、未確認事項を残す

30名の研修を選ぶ架空の見積もり3件で、料金単位を揃える方法を解説。計算式、必須条件の比較表、未確認事項を問い合わせるメールまで作ります。

AI Work Brief

ChatGPTで顧客への返信メールを作る｜分からないことを約束せず、次の対応を伝える

顧客メールと社内の確認メモから、復旧時刻を約束せずに次の対応を伝える返信を作成。コピーできる依頼文、完成返信、送信前の確認例を掲載します。

AI Work Brief

ChatGPTで取引先への断りメールを書く｜納期・範囲・代替案を、曖昧な約束にしない

追加作業を断る架空ケースで、着手日と納期、費用と対応範囲を整理。依頼文、完成メール、丁寧さを変えても条件を維持する修正例を掲載します。

AI Work Brief

ChatGPTで長い資料を要約する｜数字・脚注・未決事項を残した社内判断メモの作り方

費用・脚注・開始条件が混在したサンプル資料を、根拠付きの判断メモへ。元資料、計算式、上司向けと実務担当向けの完成例を掲載します。

AI Work Brief

ChatGPTで会議メモをTo-Doにする｜担当者・期限・未決事項を取り違えない整理方法

8行の会議メモから決定、To-Do、未決、取消を分ける実践例。担当者と相談先を区別し、メモ番号で確認できる一覧と共有メールを作ります。

AI Work Brief

ChatGPTで営業ロールプレイをする｜「今のやり方で困っていない」顧客から、検討条件を聞く練習

現状に大きな不満がない顧客との初回商談を練習。顧客役の指示、説明を急ぐ例と改善した4往復、発言を根拠にした振り返りを掲載します。

Recall Layer

教材を作り直さず、「答える」復習へ

プリントやPDFの文脈を残したまま、隠す・答える・確認する層を加えます。

Recall Layer

中学受験の塾プリントを復習に使う｜授業1回分の3枚を親子で回す例

塾のプリントが増えたとき、全部をきれいに整理し終えるまで復習を待つ必要はありません。まず授業一回分から、答える表・説明する図・解き直す問題の三枚を選びます。

Recall Layer

FPの暗記は「どこから引くか」で整理する｜必要経費・所得控除・税額控除の3例

どれも金額を差し引く仕組みに見えても、引く段階は同じではありません。制度名を覚える前に、収入・所得・税額のどこを計算しているかを固定します。

Recall Layer

行政書士の法律用語を事例から選ぶ｜取消し・無効等確認・不作為の3問

条文の語句を覚えたのに、事例を読むとどの制度か迷う。その場合は名称を増やすより、裁判所にどの結果を求めるのかを一文で整理します。

Recall Layer

高校受験の暗記を模試の復習につなぐ｜4種類の誤答から戻り先を決める

模試の点数だけを見ると、どこを復習すればよいか決まりません。用語を忘れたのか、図の読み方が違ったのか、計算で止まったのか、時間が足りなかったのかを分けると、次の教材が選べます。

Recall Layer

高校の定期テストで授業プリントを使う｜用語を答える回と、理由を説明する回を分ける

語句は覚えているのに、説明や資料の比較で止まることがあります。同じ教材でも、一周目は名称、二周目は関係、仕上げは問題で使えるか、と答え方を変えてみましょう。

Recall Layer

iPhoneで赤シート学習を始める｜教材を作り直さず「答える」復習へ

今ある教材へ「隠す・答える・確認する」を足すRecall Layerという考え方から、復習の作り方を整理します。

Recall Layer

ITパスポートの略語を利用場面で覚える｜SaaS・PaaS・IaaSを3問で見分ける

略語の日本語訳を言えても、問題文で誰が何を管理するかを取り違えると選べません。三つのクラウドサービスを、受け取るもの・自分が管理するもの・使う場面の同じ軸で比べます。

Recall Layer

中学生の定期テスト対策｜残り7日で6枚の教材を結果に合わせて並べ替える

試験範囲が出たら、すべてのページを毎日同じ回数だけ見るより、初回の確認で分からなかった理由に合わせて予定を変えます。暗記、図の説明、演習を一つに混ぜないことがポイントです。

Recall Layer

PDF教材をiPhoneで復習する｜12ページから必要な4ページを準備する例

PDFのページ数が増えると、取り込みそのものより、何を復習に使うかが曖昧になりがちです。まず用途を分け、必要な範囲のPDFを準備してから取り込みます。

Recall Layer

社会人の資格勉強をスマホで続ける｜平日10分と週末の演習をつなぐ

短い空き時間で知識を確認することと、試験の問題を解けることは同じではありません。通勤中の回想と、机での演習を往復できるよう、復習の行き先を決めます。

Recall Layer

赤シートと暗記カードを同じ教材で比較する｜手掛かりを残すか、問いを独立させるか

赤シートと暗記カードの違いは、紙かスマホかだけではありません。元のページの文脈を残すか、各問題を単独で成立させるかが違います。同じ6項目を両方にすると、使い分けが見えます。

Recall Layer

登録販売者の成分暗記を作用と注意につなぐ｜抗ヒスタミン成分の比較例

成分名を読むだけでは、働き・起こり得る副作用・注意を結び付けにくくなります。まず代表的な二つを、同じ原典の中で確認する小さな表にします。

Recall Layer

学校プリントをスマホで復習する｜6枚を「覚える・解く・戻る」に分ける

プリントを全部撮ることと、復習に使える状態にすることは別です。答えるためのページ、問題を解くページ、間違えたときの解説を分けると、撮影後の使い道が決まります。

Recall Layer

社労士の期間を起算点から覚える｜定時決定・随時改定・育休終了時改定を比べる

同じ「3か月」でも、どの月から数えるかは制度で異なります。対象月だけでなく、きっかけと適用開始を横に並べると、数字を移し替える誤りを見つけられます。

Recall Layer

宅建の数字を条件ごと覚える｜媒介契約3種類を4つの軸で比較する

5日、7日、1週間、2週間だけを別々に覚えると、登録期限と報告頻度が混ざります。同じ表に契約の種類、他社への依頼、自己発見取引、登録、報告を置いて確認します。

Recall Layer

大学受験の暗記を資料読解へつなぐ｜歴史の時系列と生物の過程で確認する

用語を見て分かることと、その知識を使って資料を説明できることは別です。暗記した情報を増やすだけでなく、同じ材料から前後関係・出発点・根拠を説明してみましょう。

Reference View

必要な情報を、作業中に消さない

SaaS、PDF、動画など、繰り返し見る情報を主作業とは別の参照として残します。

Reference View

PiPが画面共有や録画に映るか確認する｜手元と出力を分けるテスト手順

自分のMacで小窓が見えていることと、相手の画面や録画にその小窓が入ることは、別々に確かめる必要があります。設定をオンにした画面だけでは、出力結果を確認したことになりません。

Reference View

MacBookの1画面で資料を見ながら作業する｜Reference Viewという考え方

SaaSやPDFで必要な情報を作業中に消さず、主作業と参照を分けるReference Viewという考え方を整理します。

Shared Attention

画面共有と製品デモで、見る場所と操作まで共有する

ポインター、クリック、ウインドウ切り替え、範囲説明、結果確認を発話と同じ流れに揃え、参加者が迷わないデモを作ります。

4つの基本操作を、録画から切り出した短い動画で確認。1回の製品デモでどう組み合わせるかまで紹介します。

画面共有・製品デモで「どこを見るか」を伝える｜Shared Attentionとデモ支援

ポインターを示すだけでなく、クリック、ウインドウ切り替え、範囲説明、結果確認までを一つのデモの流れとして整理します。

Shared Attention
