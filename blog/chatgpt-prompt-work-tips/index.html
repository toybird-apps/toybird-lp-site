ChatGPTを仕事で使う｜用途と条件を選び、依頼文を作る

メールや要約の次に、何を任せるか。仕事の目的と完成形を選び、今回の条件を加えて依頼文を作る方法を、具体的な業務例で整理します。

ChatGPTを開いた。でも、そこから「何を渡せばいいか」「どこまで説明すればいいか」「どんな形で返してもらうか」を考え始める。AIで仕事を短くしたいのに、毎回その準備から始まることがあります。

問題は、長いプロンプトを知らないこととは限りません。仕事そのものが、まだAIへ渡せる単位に整理されていないことがあります。

Prompt Ready · Windows / macOS

Prompt Readyを使う場合は、WindowsまたはMacで40種類の用途から今日の仕事を選び、材料と条件を足して依頼文を作れます。以下の業務例で「何を頼むか」を決め、最後の手順で普段使うAIへ渡してみてください。

ChatGPTを開いてから、仕事の説明を考えている

顧客への返信、会議メモの整理、見積もり比較、資料要約、商談練習。同じChatGPTを使っても、必要な材料と「完成」の意味はすべて違います。

そこで、いきなり文章の言い回しを作るのではなく、先に仕事の骨組みを決めます。Toybird Labsでは、この作業用の短い仕様をAI Work Briefと呼びます。正式な業界標準ではなく、AIへ仕事を渡す前に何を決めるかを整理するための考え方です。

AI Work Brief：プロンプトより先に決める6項目

項目決めること例
作業AIに何をしてほしいか顧客への初動返信を作る
目的・読み手誰が何のために使うか顧客が次の連絡時刻を理解できる
元資料事実として使ってよい材料受信メール、社内確認メモ
条件変えてはいけない事実や禁止事項復旧時刻を約束しない
未確定事項分からないまま残すもの原因、復旧予定
出力次の仕事へ進める完成形送信前の返信案

「丁寧に」「分かりやすく」は最後に調整できます。先に必要なのは、AIが勝手に埋めてはいけない空欄と、仕事が終わったと判断できる形です。

今日の仕事を10の入口から選ぶ

やりたい仕事主な元資料欲しい成果Briefで先に固定すること
1. 顧客へ返信する受信メール、確認済み事実送信前の返信案約束できること／未確定
2. 取引先の依頼を断る依頼、対応範囲、代替案条件が明確な断りメール断る範囲／許可された代替案
3. 会議メモを整理する発言・決定のメモ担当・期限・未決を分けた表抽出する項目／根拠
4. 資料を要約する原資料、読み手判断に使えるメモ何を決めるための要約か
5. 候補を比較する見積もり、必須条件同じ条件の比較表比較単位／未確認値
6. 依頼内容を固める分かっていること、困りごと着手前の確認質問質問の優先順位／止める条件
7. 商談を練習する相手役、商談段階、目標会話と振り返り役割／練習終了条件
8. 相手に合わせて説明する正しい原文、読み手の前提理解しやすい説明変えてはいけない意味
9. 手順書の初稿を作る実操作メモ、例外再現できる手順試していない操作を足さない
10. 調査メモを整理する資料、出典、確認日事実と解釈を分けたメモ根拠／最新性／推測の扱い

AI活用を増やすとき、用途ごとに「魔法の文言」を覚える必要はありません。仕事が変われば、Briefの中身を変えます。

短いBriefの完成形

作業: 顧客への初動返信を作る
目的・読み手: 顧客が現在の状況と次の連絡時刻を理解できる
元資料: 顧客メール、社内確認メモ
条件: 原因や復旧時刻を推測しない
未確定事項: 原因、復旧予定
出力: そのまま確認できる返信メール案

元資料にない事実は追加しない。
重要な不足情報は、確定事項と分けて示す。

これは完成した「万能プロンプト」ではありません。仕事の境界を人が決めたBriefです。必要なら、このBriefを自然な依頼文へ変えてからAIへ渡します。

同じ元資料でも、目的が変わればBriefが変わる

8行の会議メモを例にすると、「To-Doを作る」と「顧客向けのフォローアップメールを書く」では、使う元資料が同じでも完成形が違います。前者は担当・期限・未決を正確に分けることが中心で、後者は社外へ伝えてよい情報だけを選ぶ必要があります。

元資料を使い回しても、Briefは仕事ごとに作り直します。これが「同じプロンプトを何にでも使う」方法との違いです。

AIに任せない部分もBriefへ残す

AIが文章を整えても、顧客への約束、価格、法的判断、機密情報の扱いまで自動で決めてよいとは限りません。未確定事項を空欄として残す、社内で承認された条件だけを使う、といった境界もBriefの一部です。

便利さと事実確認は分けます。読みやすい回答になっていても、原資料にない日付や条件が入っていないか、人が確認します。

期待と違ったら、Briefのどこが違うかを見る

起きたこと直すBrief修正例
文章が長すぎる出力結論と次の行動を残し、背景は3文まで
未確認の期限を確定した未確定事項・条件期限は未確認。確定事項へ移さない
社内事情が顧客向け文面に出た目的・読み手・条件社外へ伝えてよい情報だけを使う
比較表の単位が揃わない作業・条件30名で同じサービスを購入した総額へ換算

回答全体を作り直す前に、どの欄が曖昧だったかを見ると、次の依頼にも使える条件が残ります。

Prompt Readyで用途を選び、次回も使い直す

Prompt ReadyのWindows版・macOS版では、6つのカテゴリーにある40種類の用途から始められます。例えば、毎週の会議メモを整理するなら、次の流れです。

  1. 用途を選ぶ。会議メモの整理やTo-Doの作成など、今ほしい完成物に合う用途を選びます。活用アイデアから、まだ試していない使い方も探せます。
  2. 今回の材料と条件を入れる。今日のメモに加え、「担当者・期限・未決事項を分ける」「書かれていない期限は推測しない」などを含めます。読み手や出力形式も、今回の共有先に合わせます。
  3. 依頼文を確認してコピーする。利用するAIに合わせて作成した依頼文を読み、ChatGPT、Gemini、Claudeなどへ貼り付けます。回答を作るのは、貼り付け先のAIです。
  4. 次回は最近の依頼文から戻る。最近コピーした依頼文は最大20件まで端末内に保存され、復元できます。前回の日付・人名・元のメモを今回の内容へ更新してから、再びコピーします。

よく使う活用アイデアはお気に入りにしておくと、用途を探し直す手間を減らせます。前回の文章をそのまま送るのではなく、使えた条件を残し、今回の材料だけを確かめて差し替える運用です。

入力と依頼文の作成は端末内で処理され、Prompt Readyが生成AIへ自動送信することはありません。自分で外部AIへ貼り付けた後の取り扱いは、そのサービスと利用環境の条件に従います。
