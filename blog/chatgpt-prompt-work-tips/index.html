ChatGPTの使い方｜仕事で役立つプロンプトのコツと10の活用例

ChatGPTを仕事で使うための指示（プロンプト）のコツを、返信メール・会議メモの具体例と10の活用例で解説。目的・条件・出力形式の伝え方が分かります。

Toybird Labsによる実機確認・公式資料参照公開: 2026-07-30更新: 2026-08-24読了目安: 5 分

この記事で分かること

  • ChatGPTへの指示は、長さより必要な情報が入っているかが重要
  • 元になるメール、資料、メモを渡すと回答を具体化しやすい
  • 情報が足りない場合は、先に質問してもらう
  • 最初の回答を下書きとして、対話しながら改善する
  • 事実確認や最終判断は人が行う

仕事で使うプロンプトは、長さより「判断材料」を揃える

仕事の依頼では、長い説明を書くことより、ChatGPTが判断に使う情報を抜けなく渡す方が重要です。最初は次の5項目だけで十分です。

  1. 作業：何をしてほしいか
  2. 元資料：メール、会議メモ、文章、数値など
  3. 目的・読み手：誰が何のために使うか
  4. 条件：長さ、トーン、入れてはいけない内容、推測禁止など
  5. 出力形式：メール、表、箇条書き、チェックリストなど

特に重要なのは元資料です。事実を渡さず「いい感じの返信を作って」と頼むと、AI側が空白を埋める余地が大きくなります。仕事では、材料を先に揃え、分からない点は分からないまま扱わせる方が安全です。

そのまま使える基本プロンプト

角括弧の中だけ置き換えて使えます。社外秘や個人情報を外部サービスへ入力できるかは、所属組織のルールを先に確認してください。

以下の情報だけを使って作業してください。

作業: [何をしてほしいか]
目的: [何のために使うか]
読み手: [誰が読むか]
元資料: [メール、メモ、文章など]
条件: [長さ、トーン、入れてはいけない内容]
出力形式: [メール / 表 / 箇条書き など]

重要な情報が足りない場合は、推測して完成させず、先に最大3つまで質問してください。

例1：復旧時刻が未定の問い合わせへ返信する

たとえば「今朝からデータが同期されない」という問い合わせがあり、技術チームが調査中、復旧時刻は未定だとします。この場合、プロンプトでは「未確定の復旧時刻を約束しない」を条件に入れます。

回答例

お問い合わせありがとうございます。現在、同期に関する問題を技術チームで調査しています。現時点では復旧時刻を確定できていません。確認できた情報があり次第、改めてご案内します。ご不便をおかけして申し訳ありません。

文章が自然かどうかより先に、事実と未確認事項が混ざっていないかを見ます。日付、金額、復旧予定、製品仕様などは、送信前に元資料へ戻って確認します。

例2：会議メモを「要約」ではなく次の行動へ変える

会議メモでは「要約して」だけだと、読みやすい文章にはなっても、誰が何をするかが埋もれることがあります。出力を先に決めると実務で使いやすくなります。

次の会議メモから、以下を分けて整理してください。
1. 決定事項
2. To-Do（担当者・期限）
3. 未決事項
4. 次回までに確認が必要な質問

担当者や期限が書かれていない場合は推測せず「未確認」としてください。

仕事で使いやすい10の活用例

同じ基本形でも、元資料と出力形式を変えるだけで用途は広がります。

1. 返信メール

受信内容、確認済み事実、次の対応を渡して下書きを作る。

2. 会議後のTo-Do整理

決定事項、担当者、期限、未決事項を分ける。

3. 長文資料の要約

読む人と判断目的を指定し、残す情報を変える。

4. 選択肢の比較

比較軸と優先順位を決め、不明項目を未確認として残す。

5. 顧客向けへの書き換え

事実を変えず、専門用語と文章量だけを調整する。

6. 質問リスト作成

提案書や仕様書から、判断に必要な不足情報を洗い出す。

7. 営業ロールプレイ

相手役、商談段階、会話ルールを決めて一問ずつ練習する。

8. 手順書のたたき台

実際の作業メモから、順序・注意点・確認項目を整理する。

9. 調査結果の整理

出典、確認日、事実と解釈を分けてまとめる。

10. 既存文章の改善

「短くする」「結論を先にする」など、直す場所を限定して依頼する。

最初の回答を完成品だと思わず、直す場所だけ指定する

期待と違うときに、毎回プロンプトを最初から書き直す必要はありません。「もっと良くして」ではなく、差分を具体的に伝えます。

  • 長すぎる → 「半分の長さにし、結論を最初に」
  • 断定が強い → 「未確認事項は断定せず、確認が必要と明記」
  • 専門的すぎる → 「初めて読む顧客向けに専門用語を減らす」
  • 形式が使いにくい → 「決定事項・To-Do・未決事項の3列にする」

変更点を限定すると、良かった部分を残しながら修正できます。

送信・共有の前に人が確認する5項目

  • 名前、日付、金額、製品名が元資料と一致しているか
  • 資料にない事実や約束が追加されていないか
  • 未確認事項を、確定事項のように書いていないか
  • 機密情報や個人情報の扱いが社内ルールに合っているか
  • 読み手に必要な次の行動が明確か

ChatGPTは下書きや整理を速くする道具として使い、最終判断と事実確認は人が持つ、という分担にすると仕事へ組み込みやすくなります。

よくある質問

ChatGPTへの指示は長いほど良いのでしょうか？

長ければ良いわけではありません。何をしてほしいのか、目的、条件、回答形式など、判断に必要な情報が含まれていることが重要です。不要な説明が多すぎると、重要な条件が分かりにくくなる場合もあります。

ChatGPTの回答が期待と違う場合はどうすればよいですか？

どこが違うのかを具体的に伝えて修正を依頼します。「もっと良くして」ではなく、半分の長さにする、結論を最初に置く、専門用語を減らす、顧客向けの丁寧な表現にするなど、変更箇所を明確にします。

何を指示すればよいか分からない場合はどうすればよいですか？

最初に、必要な情報をChatGPT側から質問してもらう方法があります。「この作業を進めるために必要な情報を、一度に一つずつ質問してください」と伝え、質問に回答しながら目的や条件を整理します。
