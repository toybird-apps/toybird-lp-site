ChatGPTで長い資料を要約する方法｜仕事向けプロンプト例

ChatGPTで長い資料や文章を仕事向けに要約する方法を解説。経営者向け、実務担当者向け、顧客説明向けに残す情報を変えるプロンプト例を紹介します。

Toybird Labsによる実機確認・公式資料参照公開: 2026-08-03更新: 2026-08-24読了目安: 4 分

この記事で分かること

  • 要約の前に、誰が何を判断するために読むかを決める
  • 残す項目、削る項目、長さ、出力形式を指定する
  • 資料にない事実や結論を追加しないようにする
  • 長い資料は、構成確認・部分要約・全体統合の順に分ける
  • 重要な数字、日付、引用は元資料と照合する

要約の前に「誰が、何を判断するために読むか」を決める

同じ資料でも、経営者が投資判断のために読む要約と、実務担当者が次の作業を確認する要約では残す情報が違います。「短くして」だけではなく、読み手と用途を最初に指定します。

  • 経営判断向け：結論、数値、リスク、選択肢、未確定事項
  • 実務担当向け：手順、担当、期限、依存関係、例外
  • 顧客説明向け：相手に関係する変更、影響、次の行動

長い資料を要約する基本プロンプト

以下の資料を、[読み手] が [判断・作業] のために読めるように要約してください。

必ず残す項目:
- [項目1]
- [項目2]
- 数字、期限、例外、リスク

条件:
- 資料にない事実や結論を追加しない
- 判断できない点は「資料内で確認できない」と書く
- 重要な数値は元の表現を残す

出力:
1. 3行の結論
2. 重要ポイント
3. リスク・例外
4. 確認が必要な点
5. 次のアクション

長い資料は「構成確認 → 部分要約 → 全体統合」に分ける

一度に扱うより、まず章立てと論点を確認し、章ごとに同じ形式で要約した後、その要約だけを材料に全体を統合すると抜けを確認しやすくなります。

  1. 見出し・章・付録を一覧にする
  2. 各章を同じ項目で要約する
  3. 章ごとの重複と矛盾を確認する
  4. 最後に読み手向けの全体要約を作る

分割するときは「第1部」「第2部」のように番号を振り、あとでどこから出た情報か戻れるようにします。

重要な結論には、元資料へ戻れる手掛かりを残す

数値や条件が重要な資料では、要約だけを読むと確認場所が分からなくなります。ページ番号、章名、見出しなど、元資料へ戻るための情報も一緒に出すよう指示します。

重要な数値・期限・リスクには、可能な範囲で元資料の章名または見出しを添えてください。
引用する場合は、資料にある表現と要約を区別してください。

読み手別に残す情報を変える

経営者向け

結論、影響額、選択肢、主要リスク、決めるべき事項を先にします。

実務担当者向け

手順、担当、期限、前提条件、例外を残します。

顧客向け

内部事情を削り、顧客への影響と必要な行動に絞ります。社外秘が混ざらないかを人が確認します。

要約を使う前に元資料と照合する項目

  • 数値、日付、固有名詞
  • 「必須」「推奨」など条件の強さ
  • 例外や但し書き
  • 資料の結論とAIの解釈が混ざっていないか
  • 重要な章が要約から抜けていないか

例：30ページの提案資料を社内判断用にまとめる

たとえば提案資料を上司へ共有する場合、ページ順に短くするだけでは判断材料が埋もれます。最初に「採用判断に必要な情報」を固定し、価格、導入時期、前提条件、制約、未確定事項だけを章ごとに拾います。

  1. 目次と各章の役割を確認する
  2. 価格・スケジュール・要件・リスクを同じ見出しで各章から抽出する
  3. 同じ数値が複数箇所にある場合は差異を確認する
  4. 最後に「判断できること／まだ判断できないこと」を分けて1ページ相当にまとめる

この順番なら、AIの要約をそのまま正解として扱わず、元資料へ戻りながら不足を確認できます。

表・脚注・付録を本文と同じ扱いにしない

長い資料では、重要な条件が本文ではなく表の注記や付録に置かれていることがあります。要約対象を本文だけに限定すると、価格条件、例外、対象外範囲などが落ちる可能性があります。

「表と脚注にある条件も確認し、本文と矛盾する場合は別に列挙する」と指定し、PDFのレイアウトが崩れて読み取れない場合は無理に推測させず、該当ページを人が確認します。

実機で確認した範囲

Prompt Ready

Prompt Readyで用途を選び、事実・読み手・禁止事項・出力形式を変えながら、作成される依頼文の差を確認しました。アプリはAIへ自動送信せず、貼り付け前に人が確認できます。

  • 日付・金額・製品仕様は、元資料と照合する
  • 外部AIに渡せない機密情報や個人情報を入力しない
  • 生成結果をそのまま送らず、読み手と事実を確認する

よくある質問

ChatGPTでPDFやWordの資料を要約できますか？

ファイル添付に対応している利用環境では、一般的な文書ファイルを扱える場合があります。利用できる形式や上限はプランと時期によって変わるため、現在の画面や公式案内を確認してください。

長い文章を一度に貼り付けられない場合はどうすればよいですか？

章や見出しごとに分け、同じ出力形式で部分要約を作ります。各部分に番号を付け、最後にそれらだけを材料として全体要約を作ります。

要約に重要な内容が抜ける場合はどうすればよいですか？

必ず残す項目を具体的に列挙し、数字、期限、例外、リスクなどを別見出しにします。元資料と要約の対応表を作らせる方法もあります。
