Cómo resumir documentos largos con ChatGPT para el trabajo

Resume documentos largos con ChatGPT definiendo el lector, la decisión, la extensión, las pruebas necesarias y el tratamiento de la información ausente.

3 de agosto de 202610 min de lecturaMasaki Iino

Un buen resumen no es simplemente una versión más corta. Conserva la información que un lector concreto necesita para una decisión concreta. El mismo informe requiere enfoques distintos para dirección, un equipo de proyecto o clientes.

Al final tendrás un prompt reutilizable, un ejemplo completo y una lista breve para revisar el resultado antes de usarlo en el trabajo.

Lo que podrás hacer

  • Define quién leerá el resumen y qué decisión debe tomar.
  • Especifica las secciones y la extensión máxima.
  • Mantén localizables los números, fechas y riesgos importantes.
  • Separa conclusiones no respaldadas e información ausente.

Por qué una instrucción breve suele quedarse corta

Una instrucción breve como «Resume este documento.» puede generar un texto correcto, pero no explica el contexto, el destinatario, los límites ni el formato. ChatGPT debe completar esos vacíos y puede producir frases genéricas o suposiciones no respaldadas.

Qué conviene indicar antes de pedir la respuesta

Antes de pedir la respuesta final, prepara la información siguiente. No hace falta escribir un prompt largo; cada elemento debe incluir solo el detalle que realmente cambia el resultado.

  1. El lector y su nivel de conocimiento
  2. El objetivo o la decisión que debe apoyar el resumen
  3. La extensión máxima o el tiempo de lectura
  4. Las secciones obligatorias: conclusión, impacto, riesgos y acciones
  5. El tratamiento de citas, cifras e información incierta

Prompt listo para usar

Sustituye el texto entre corchetes por tu situación. Elimina o anonimiza la información confidencial y verifica el resultado con la fuente antes de utilizarlo.

Prompt listo para usar
Resume el documento siguiente para [lector].
Objetivo: ayudarle a [decisión o acción].
Extensión máxima: [palabras o tiempo de lectura].
Secciones obligatorias:
1. Conclusión principal
2. Evidencias y cifras importantes
3. Impacto en nuestro trabajo
4. Riesgos o asuntos pendientes
5. Próximas acciones recomendadas

Utiliza únicamente el documento. Conserva con precisión fechas, cifras y condiciones. Si el documento no respalda una conclusión, escribe “No consta en la fuente”.

Documento:
[pega el texto]

Ejemplo: Resumen de tres minutos para una responsable de departamento

Un informe de implantación incluye avances, retrasos, cambios de presupuesto y decisiones pendientes de dirección.

Conclusión principal: El lanzamiento sigue siendo posible este trimestre, pero es necesario aprobar el calendario revisado de pruebas.

Evidencias: Quedan dos pruebas críticas. El impacto presupuestario descrito se limita a una revisión externa adicional.

Decisión requerida: Aprobar las nuevas fechas y confirmar quién se encargará de la comunicación a clientes.

Qué revisar antes de usar el resultado

Un texto bien redactado todavía puede incluir un dato incorrecto o un compromiso inadecuado. Revisa estos puntos antes de compartirlo.

  • Las cifras y fechas importantes coinciden con la fuente.
  • El resumen sirve al lector y a la decisión indicados.
  • Las recomendaciones están separadas de los hechos.
  • La eliminación de contexto no cambia el significado.
  • La información confidencial se trata según la política aplicable.

Preguntas frecuentes

¿Puede ChatGPT resumir un documento que supera el límite de entrada?

Divídelo en secciones lógicas, resume cada una con los mismos criterios y utiliza después esos resúmenes para una síntesis final.

¿Cómo evito que desaparezcan detalles importantes?

Enumera lo que debe conservarse: fechas, cifras, obligaciones, riesgos y decisiones.

¿Puedo tomar una decisión sin leer la fuente?

En decisiones importantes, no. Utiliza el resumen para localizar y verificar las partes relevantes del documento.

¿Cómo debo tratar las tablas?

Incluye la tabla o describe claramente sus columnas y verifica cada cifra del resumen con el original.
