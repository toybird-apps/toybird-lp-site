Cómo resumir documentos largos con ChatGPT según un objetivo de negocio

Un buen resumen se diseña para un lector y una decisión, no solo para reducir la longitud.

3 de agosto de 202610 min de lecturaPor Masaki Iino

Esta guía muestra una forma práctica de usar ChatGPT en el trabajo. El objetivo no es memorizar un “prompt mágico”, sino aportar el contexto, las condiciones y el formato de salida que necesita cada tarea.

Puedes copiar el ejemplo, sustituir los datos entre corchetes y revisar el resultado antes de utilizarlo en una situación real.

Puntos clave

  • Define quién leerá el resumen y qué decisión debe tomar.
  • Especifica secciones, longitud máxima e información que no debe desaparecer.
  • Pide distinguir las afirmaciones del documento de la interpretación de la IA.
  • Incluye referencias a páginas o secciones cuando sea importante comprobar el origen.
  • Compara cifras, fechas, excepciones y recomendaciones con la fuente.

Un enfoque más fiable

Indica lector, objetivo, longitud, secciones obligatorias y hechos o excepciones que no deben omitirse.

Información que conviene aportar

  • El documento completo o las secciones relevantes
  • El lector y su nivel de conocimiento
  • La decisión o acción que debe apoyar el resumen
  • Títulos, longitud y nivel de detalle
  • Reglas para referencias, dudas y contradicciones

Plantilla reutilizable

Sustituye las partes entre corchetes por tu situación. Pide a la IA que no invente datos y que separe las preguntas pendientes.

Plantilla reutilizable
## Tarea
Resume el documento para [lector].

## Objetivo
El lector necesita el resumen para [decisión o acción].

## Fuente
[Pega el texto o adjunta el documento]

## Salida
1. Conclusión principal
2. Hechos y cifras clave
3. Impacto para el negocio
4. Acciones necesarias
5. Riesgos, excepciones y preguntas pendientes

## Condiciones
- Mantén el resumen dentro de [longitud].
- No añadas información que no esté en la fuente.
- Distingue las afirmaciones de la fuente de tu interpretación.
- Conserva fechas, importes, condiciones y excepciones importantes.
- Incluye referencias a páginas o secciones cuando existan.

Ejemplo: resumen de tres minutos para un responsable de departamento

Un responsable debe revisar una propuesta de implantación antes de aprobar un piloto. Le importan el coste, la carga de trabajo, los riesgos y la decisión, no toda la historia del proyecto.

Ejemplo práctico
Resume esta propuesta para un responsable que dispone de tres minutos. Utiliza: conclusión, beneficio esperado, coste y carga de trabajo, riesgos y decisión necesaria. Conserva fechas, importes, dependencias y condiciones. No añadas recomendaciones sin respaldo.

Ejemplo práctico

Conclusión: La propuesta recomienda un piloto de tres meses en un departamento.

Coste y carga: [importe confirmado] y [recursos confirmados].

Riesgos: La migración y la adopción requieren medidas específicas.

Decisión: aprobar o rechazar el presupuesto antes de [fecha confirmada].

Revisión antes de usar el resultado

Utiliza el resultado como borrador. Comprueba nombres, fechas, precios, compromisos y políticas internas antes de enviarlo o tomar una decisión.

  • El resumen corresponde al lector y a la decisión solicitada.
  • Las cifras, fechas, condiciones y excepciones coinciden con la fuente.
  • El contexto se redujo sin eliminar información necesaria.
  • Las opiniones no se presentan como hechos de la fuente.
  • Las afirmaciones críticas pueden localizarse en el documento.
No introduzcas datos personales, información confidencial de clientes, contratos ni información interna no publicada salvo que tu organización lo permita. Sustituye nombres y cifras por datos de ejemplo cuando sea necesario.

Preguntas frecuentes

¿ChatGPT puede resumir un PDF?

Según el servicio, puede ser posible cargarlo. Comprueba si se han leído correctamente tablas, imágenes, notas y páginas escaneadas.

¿Qué longitud debe tener un resumen?

Depende del uso: unas viñetas para una actualización, una página para una decisión o un resumen por secciones para una revisión detallada.

¿Cómo evito que desaparezcan las excepciones importantes?

Indica de forma explícita qué debe conservarse: requisitos, exclusiones, plazos, dependencias y condiciones.

Prompt Ready es una aplicación para Windows y macOS que ayuda a crear instrucciones estructuradas para ChatGPT, Gemini, Claude y otros servicios de IA. Elige una tarea, añade el texto de origen y las condiciones, y copia una instrucción lista para usar.

Prompt Ready procesa el texto de forma local y no lo envía automáticamente a un servicio de IA externo ni al servidor del desarrollador. Cuando pegues la instrucción en un servicio de IA, se aplicará la política de datos de ese servicio.
