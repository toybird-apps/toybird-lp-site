Cómo redactar un correo de rechazo educado con ChatGPT

Redacta con ChatGPT un correo profesional para rechazar una solicitud, explicar la limitación, proponer una alternativa y dejar claro el siguiente paso.

3 de agosto de 20269 min de lecturaMasaki Iino

Un rechazo profesional debe cuidar la relación sin ocultar la decisión. ChatGPT puede ayudar con la redacción si se define con claridad qué no se puede aceptar, qué alternativa es real y qué datos no deben modificarse.

Al final tendrás un prompt reutilizable, un ejemplo completo y una lista breve para revisar el resultado antes de usarlo en el trabajo.

Lo que podrás hacer

  • Indica con claridad qué parte de la solicitud no puedes aceptar.
  • Explica solo lo necesario para que la decisión se entienda.
  • Propón una alternativa realista cuando exista.
  • Termina con una pregunta o un siguiente paso concreto.

Por qué una instrucción breve suele quedarse corta

Una instrucción breve como «Escribe un correo amable para rechazar esta solicitud.» puede generar un texto correcto, pero no explica el contexto, el destinatario, los límites ni el formato. ChatGPT debe completar esos vacíos y puede producir frases genéricas o suposiciones no respaldadas.

Qué conviene indicar antes de pedir la respuesta

Antes de pedir la respuesta final, prepara la información siguiente. No hace falta escribir un prompt largo; cada elemento debe incluir solo el detalle que realmente cambia el resultado.

  1. Quién es el destinatario y qué relación existe
  2. La solicitud exacta que debes rechazar
  3. La limitación o razón ya confirmada
  4. La fecha, alcance o condición alternativa que sí puedes ofrecer
  5. El tono deseado y las expresiones que conviene evitar

Prompt listo para usar

Sustituye el texto entre corchetes por tu situación. Elimina o anonimiza la información confidencial y verifica el resultado con la fuente antes de utilizarlo.

Prompt listo para usar
Redacta un correo profesional para rechazar la siguiente solicitud.
Destinatario: [cliente, proveedor o colaborador]
Solicitud recibida: [describe la solicitud]
Lo que no podemos aceptar: [alcance, fecha, precio o condición]
Razón confirmada: [explicación breve y factual]
Alternativa que podemos ofrecer: [opción realista]
Siguiente paso: [qué debe confirmar el destinatario]
Tono: respetuoso, sereno y directo.

No inventes fechas, aprobaciones ni concesiones. Incluye asunto y cuerpo del correo.

Ejemplo: Rechazar un trabajo adicional solicitado para esta semana

Un colaborador pide realizar una tarea adicional antes del viernes. El equipo no puede terminarla esta semana, pero sí el miércoles siguiente.

Asunto: Plazo para el trabajo adicional

Gracias por enviarnos la solicitud adicional. Con la planificación actual no podremos completar el trabajo esta semana. Sí podemos finalizarlo el próximo miércoles.

¿Podría confirmarnos si ese plazo le resulta adecuado? Gracias por su comprensión.

Cómo adaptar el prompt a otras situaciones

La estructura principal se mantiene, pero los hechos, el público y el formato deben cambiar según la tarea.

Rechazar un adelanto de fecha

Indica la fecha solicitada y la primera fecha que puede comprometerse sin reducir la calidad.

Rechazar un descuento

Explica que el precio ofrecido es definitivo y plantea una alternativa no económica solo si está aprobada.

No aceptar una propuesta

Agradece el envío, comunica que no se continuará por ahora y evita valorar negativamente el producto.

Qué revisar antes de usar el resultado

Un texto bien redactado todavía puede incluir un dato incorrecto o un compromiso inadecuado. Revisa estos puntos antes de compartirlo.

  • La negativa es clara y no queda escondida tras expresiones ambiguas.
  • La alternativa está disponible y autorizada.
  • La disculpa no implica una responsabilidad que no se ha confirmado.
  • Fechas, precios y condiciones coinciden con la decisión interna.
  • El destinatario sabe qué debe hacer a continuación.

Preguntas frecuentes

¿Cuánto detalle debo dar sobre el motivo?

Incluye el contexto necesario para entender la decisión, pero evita información interna innecesaria o datos sobre otros clientes.

¿Cómo puedo ser educado sin crear falsas expectativas?

Utiliza un tono respetuoso y expresa después el límite con claridad. “No podremos terminarlo el viernes” es más claro que “el viernes será complicado”.

¿Qué hago si no existe una alternativa?

Indícalo de forma directa, agradece la solicitud y explica el siguiente paso relevante.

¿Puede ChatGPT decidir qué concesión ofrecer?

Puede proponer ideas, pero una persona autorizada debe aprobar fechas, descuentos, alcance o cambios contractuales.
