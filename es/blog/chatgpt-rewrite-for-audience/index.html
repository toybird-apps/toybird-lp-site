IA generativa y productividad

Cómo adaptar un texto para clientes, directivos o equipos con ChatGPT

Cambia la explicación, el vocabulario y el énfasis sin modificar los hechos.

3 de agosto de 20269 min de lecturaPor Masaki Iino

Esta guía muestra una forma práctica de usar ChatGPT en el trabajo. El objetivo no es memorizar un “prompt mágico”, sino aportar el contexto, las condiciones y el formato de salida que necesita cada tarea.

Puedes copiar el ejemplo, sustituir los datos entre corchetes y revisar el resultado antes de utilizarlo en una situación real.

Puntos clave

  • Define qué sabe el nuevo lector y qué debe hacer.
  • Enumera los hechos, términos y advertencias que deben permanecer.
  • Especifica tono, longitud, vocabulario y llamada a la acción.
  • Pide señalar la información que no puede adaptarse sin confirmación.
  • Compara el nuevo texto con la fuente para evitar cambios de significado.

Un enfoque más fiable

Describe el conocimiento del lector, el objetivo, el tono y la siguiente acción y establece qué hechos, términos, cifras y límites deben mantenerse.

Información que conviene aportar

  • El texto original y sus hechos verificados
  • El nuevo público y lo que ya sabe
  • El objetivo del texto adaptado
  • Tono, longitud, vocabulario y estructura
  • Detalles que no deben cambiar o necesitan explicación

Plantilla reutilizable

Sustituye las partes entre corchetes por tu situación. Pide a la IA que no invente datos y que separe las preguntas pendientes.

Plantilla reutilizable
## Tarea
Adapta el texto de origen para [público].

## Objetivo
El lector debe entender [punto principal] y después [siguiente acción].

## Texto de origen
[Pega el texto]

## Orientación sobre el público
- Conocimiento previo: [principiante / especialista / directivo / cliente]
- Tono: [formal / cercano / conciso]
- Longitud: [longitud]
- Términos que deben explicarse o evitarse: [lista]

## Conservar exactamente
- [hechos, cifras, nombres, texto legal, limitaciones]

## Condiciones
- No añadas beneficios, afirmaciones ni promesas que no estén en la fuente.
- Si la fuente es ambigua, indica el punto para confirmación en vez de convertirlo en un hecho.
- Mantén el significado y cambia la forma de explicarlo.

Ejemplo: adaptar una nota técnica para un cliente nuevo

El texto original está dirigido a ingeniería y se centra en la implementación. El cliente necesita comprender el beneficio práctico, los requisitos y la limitación sin jerga técnica.

Ejemplo práctico
Adapta esta nota para clientes que usan el producto por primera vez. Explica primero el beneficio, utiliza lenguaje sencillo y conserva exactamente los sistemas compatibles y la limitación conocida. No añadas afirmaciones sobre rendimiento. Termina con un siguiente paso.

Ejemplo práctico

La actualización facilita [beneficio verificado]. Está disponible en [sistemas confirmados]. Antes de activarla, ten en cuenta [limitación confirmada]. Para comenzar, abre [ubicación confirmada] y sigue los pasos.

Revisión antes de usar el resultado

Utiliza el resultado como borrador. Comprueba nombres, fechas, precios, compromisos y políticas internas antes de enviarlo o tomar una decisión.

  • El texto conserva todos los hechos y límites importantes.
  • El nuevo público entiende la idea sin jerga interna.
  • El tono es apropiado sin ser promocional o impreciso.
  • La llamada a la acción coincide con lo que el lector puede hacer.
  • No se añadió ningún beneficio, comparación o promesa sin respaldo.
No introduzcas datos personales, información confidencial de clientes, contratos ni información interna no publicada salvo que tu organización lo permita. Sustituye nombres y cifras por datos de ejemplo cuando sea necesario.

Preguntas frecuentes

¿Adaptar es lo mismo que resumir?

No. Adaptar cambia la explicación para otro público; resumir también reduce la información. Se pueden pedir ambas cosas, pero indica qué hechos deben conservarse.

¿Cómo mantengo términos técnicos importantes?

Inclúyelos en “Conservar exactamente” y pide una explicación sencilla junto a ellos en vez de sustituirlos.

¿Puedo crear varias versiones a la vez?

Sí. Pide una versión separada para cada público y define el objetivo y la longitud máxima de cada una.

Prompt Ready incluye “Adaptar a otro público”, con opciones de destinatario, tono, idioma, dudas y formato. Así puedes reutilizar las condiciones sin empezar de cero.

Prompt Ready está disponible en español tanto en la interfaz como en la generación de instrucciones para IA.

Prompt Ready es una aplicación para Windows y macOS que ayuda a crear instrucciones estructuradas para ChatGPT, Gemini, Claude y otros servicios de IA. Elige una tarea, añade el texto de origen y las condiciones, y copia una instrucción lista para usar.

Prompt Ready procesa el texto de forma local y no lo envía automáticamente a un servicio de IA externo ni al servidor del desarrollador. Cuando pegues la instrucción en un servicio de IA, se aplicará la política de datos de ese servicio.

Adapta la explicación, no los hechos verificados

Una buena adaptación cambia el vocabulario, el orden y el énfasis para que el lector actúe, pero no modifica límites, cifras, obligaciones ni otra información verificada.
