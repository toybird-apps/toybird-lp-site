Cómo adaptar un texto a distintos públicos con ChatGPT

Utiliza ChatGPT para presentar los mismos hechos a clientes, dirección, equipos internos o principiantes sin cambiar el significado.

3 de agosto de 202610 min de lecturaMasaki Iino

Adaptar un texto a otro público no consiste solo en cambiar el tono. Cada lector necesita vocabulario, contexto, detalle y acciones diferentes. El prompt debe indicar qué hechos permanecen fijos y qué se puede simplificar.

Al final tendrás un prompt reutilizable, un ejemplo completo y una lista breve para revisar el resultado antes de usarlo en el trabajo.

Lo que podrás hacer

  • Nombra al nuevo lector y lo que ya conoce.
  • Indica el objetivo de la nueva versión.
  • Separa los hechos fijos de la redacción que puede cambiar.
  • Define tono, extensión, terminología y acción esperada.

Por qué una instrucción breve suele quedarse corta

Una instrucción breve como «Reescribe este texto para clientes.» puede generar un texto correcto, pero no explica el contexto, el destinatario, los límites ni el formato. ChatGPT debe completar esos vacíos y puede producir frases genéricas o suposiciones no respaldadas.

Qué conviene indicar antes de pedir la respuesta

Antes de pedir la respuesta final, prepara la información siguiente. No hace falta escribir un prompt largo; cada elemento debe incluir solo el detalle que realmente cambia el resultado.

  1. El texto de origen
  2. El público objetivo y su nivel de conocimiento
  3. El propósito de la nueva versión
  4. Los hechos, cifras y condiciones que deben mantenerse
  5. El tono, la extensión, el vocabulario y el formato

Prompt listo para usar

Sustituye el texto entre corchetes por tu situación. Elimina o anonimiza la información confidencial y verifica el resultado con la fuente antes de utilizarlo.

Prompt listo para usar
Reescribe el texto de origen para [público objetivo].
Objetivo: [qué debe comprender o hacer el lector].
Conocimiento del lector: [principiante, especialista, dirección, cliente, etc.]
Mantener sin cambios: [hechos, fechas, cifras, nombres y compromisos]
Cambiar: [tono, vocabulario, nivel de detalle y extensión]
Formato de salida: [correo, aviso, resumen, instrucciones, etc.]

No añadas afirmaciones que no estén en el texto de origen. Después de reescribir, enumera las frases ambiguas del original.

Texto:
[pega el texto]

Ejemplo: Adaptar una nota de producto para clientes, dirección y equipo interno

Una nueva función de exportación reduce el trabajo manual, pero un administrador debe activar un permiso antes de que los usuarios puedan verla.

Versión para clientes: La nueva opción de exportación reducirá el tiempo dedicado a dar formato a los informes. Es posible que su administrador deba activar el acceso.

Versión para dirección: La versión puede reducir el trabajo manual; la adopción depende de que los administradores activen el permiso.

Versión interna: Actualizar la guía, confirmar los permisos predeterminados y preparar una respuesta para usuarios que no vean la función.

Cómo adaptar el prompt a otras situaciones

La estructura principal se mantiene, pero los hechos, el público y el formato deben cambiar según la tarea.

Texto técnico para principiantes

Explica los términos necesarios con lenguaje sencillo e incluye un ejemplo concreto.

Actualización larga para dirección

Empieza por la decisión, el impacto y el riesgo, y deja los detalles en viñetas.

Solicitud de cliente para el equipo interno

Convierte la petición en comportamiento requerido, criterios de aceptación y preguntas abiertas.

Qué revisar antes de usar el resultado

Un texto bien redactado todavía puede incluir un dato incorrecto o un compromiso inadecuado. Revisa estos puntos antes de compartirlo.

  • Los hechos y compromisos no han cambiado.
  • El lector puede comprender el texto sin contexto ausente.
  • El tono encaja con la relación y el canal.
  • Los términos técnicos se explican o se conservan por un motivo.
  • La llamada a la acción es adecuada para el público.

Preguntas frecuentes

¿Puede ChatGPT cambiar el significado al reescribir?

Sí. Indica qué hechos y condiciones deben permanecer y compara la nueva versión con el original.

¿Cómo hago que un texto sea más accesible?

Pide lenguaje claro, frases cortas, un ejemplo y explicaciones para los términos imprescindibles.

¿Todos los públicos necesitan el mismo detalle?

No. Mantén la misma verdad, pero selecciona el detalle necesario para la decisión o la acción de cada lector.

¿Puedo crear varias versiones a la vez?

Sí. Solicita versiones etiquetadas y define para cada una público, objetivo y extensión.
