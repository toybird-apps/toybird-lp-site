Cómo convertir notas de reunión en tareas con ChatGPT: responsables, fechas y pendientes

Transforma notas desordenadas en una lista de acciones sin adivinar responsables ni fechas.

3 de agosto de 20269 min de lecturaPor Masaki Iino

Esta guía muestra una forma práctica de usar ChatGPT en el trabajo. El objetivo no es memorizar un “prompt mágico”, sino aportar el contexto, las condiciones y el formato de salida que necesita cada tarea.

Puedes copiar el ejemplo, sustituir los datos entre corchetes y revisar el resultado antes de utilizarlo en una situación real.

Puntos clave

  • Aclara que el objetivo es hacer seguimiento de acciones, no solo acortar el texto.
  • Separa decisiones, tareas, responsables, fechas y asuntos pendientes.
  • Usa “Sin confirmar” cuando falte un responsable o una fecha.
  • Conserva la relación con el texto original para poder comprobar cada tarea.
  • Revisa nombres y compromisos antes de compartir la lista.

Un resumen genérico puede ocultar las acciones que deben realizarse

Resume estas notas de reunión.

Un enfoque más fiable

Especifica que los participantes deben ver decisiones, tareas, responsables, fechas y asuntos que todavía requieren una decisión.

Información que conviene aportar

  • Las notas o la transcripción completa
  • El objetivo y la fecha de la reunión
  • Las secciones que debe tener la salida
  • La regla de no inventar responsables ni fechas
  • El nivel de detalle y el público destinatario

Plantilla reutilizable

Sustituye las partes entre corchetes por tu situación. Pide a la IA que no invente datos y que separe las preguntas pendientes.

Plantilla reutilizable
## Tarea
Organiza las notas de reunión para que el equipo pueda revisar rápidamente decisiones y próximas acciones.

## Notas
[Pega las notas]

## Salida
1. Resumen breve
2. Decisiones tomadas
3. Tabla de tareas con acción, responsable y fecha
4. Asuntos pendientes
5. Preguntas que requieren confirmación

## Condiciones
- No inventes responsables, fechas ni decisiones.
- Escribe “Sin confirmar” cuando falte información.
- Une notas duplicadas, pero no ocultes afirmaciones contradictorias.
- Formula cada tarea como una acción concreta.

Ejemplo: preparación del lanzamiento de un producto

El lanzamiento está previsto para el 20 de agosto. Tanaka actualizará la página de ayuda antes del 15. Las pruebas deben terminar el 18, pero todavía no hay responsable. La fecha del aviso a clientes sigue pendiente.

Ejemplo práctico
Organiza estas notas en resumen, decisiones, tareas con responsable y fecha y asuntos pendientes. No inventes datos. Marca como “Sin confirmar” al responsable de las pruebas y la fecha del aviso a clientes.

Ejemplo práctico

Decisión: Mantener el 20 de agosto como fecha prevista de lanzamiento.

Tareas:
- Actualizar la página de ayuda — Responsable: Tanaka — Fecha: 15 de agosto
- Completar las pruebas — Responsable: Sin confirmar — Fecha: 18 de agosto

Pendiente: decidir cuándo se enviará el aviso a clientes.

Revisión antes de usar el resultado

Utiliza el resultado como borrador. Comprueba nombres, fechas, precios, compromisos y políticas internas antes de enviarlo o tomar una decisión.

  • Cada tarea comienza con una acción concreta.
  • Los responsables y las fechas coinciden con las notas originales.
  • La información ausente aparece como pendiente y no como una suposición.
  • Las decisiones están separadas de propuestas y comentarios.
  • Las contradicciones no se han combinado en silencio.
No introduzcas datos personales, información confidencial de clientes, contratos ni información interna no publicada salvo que tu organización lo permita. Sustituye nombres y cifras por datos de ejemplo cuando sea necesario.

Preguntas frecuentes

¿ChatGPT puede crear un acta formal a partir de notas informales?

Sí, pero indica el formato utilizado por tu organización y comprueba asistentes, decisiones y compromisos frente al registro original.

¿Qué hago si aparecen varias fechas para la misma tarea?

Pide que muestre el conflicto en vez de elegir una fecha. Una persona debe confirmar la correcta.

¿Conviene pegar una transcripción completa?

Puede ayudar, pero elimina información confidencial y pide referencias a marcas de tiempo o turnos cuando la trazabilidad sea importante.

Prompt Ready está disponible en español tanto en la interfaz como en la generación de instrucciones para IA.

Prompt Ready es una aplicación para Windows y macOS que ayuda a crear instrucciones estructuradas para ChatGPT, Gemini, Claude y otros servicios de IA. Elige una tarea, añade el texto de origen y las condiciones, y copia una instrucción lista para usar.

Prompt Ready procesa el texto de forma local y no lo envía automáticamente a un servicio de IA externo ni al servidor del desarrollador. Cuando pegues la instrucción en un servicio de IA, se aplicará la política de datos de ese servicio.
