Cómo convertir notas de reunión en tareas con ChatGPT

Utiliza ChatGPT para separar decisiones, tareas, responsables, fechas límite y asuntos pendientes a partir de notas de reunión desordenadas.

3 de agosto de 20269 min de lecturaMasaki Iino

Un resumen explica lo que se habló; una lista de tareas permite saber qué debe ocurrir después. Si defines las columnas y prohíbes las suposiciones, ChatGPT puede transformar notas informales en un documento de seguimiento.

Al final tendrás un prompt reutilizable, un ejemplo completo y una lista breve para revisar el resultado antes de usarlo en el trabajo.

Lo que podrás hacer

  • Separa decisiones, propuestas y preguntas abiertas.
  • Extrae responsable y fecha solo cuando aparecen en las notas.
  • Marca los datos ausentes como “sin confirmar”.
  • Conserva una referencia a las notas originales.

Por qué una instrucción breve suele quedarse corta

Una instrucción breve como «Resume estas notas de reunión.» puede generar un texto correcto, pero no explica el contexto, el destinatario, los límites ni el formato. ChatGPT debe completar esos vacíos y puede producir frases genéricas o suposiciones no respaldadas.

Qué conviene indicar antes de pedir la respuesta

Antes de pedir la respuesta final, prepara la información siguiente. No hace falta escribir un prompt largo; cada elemento debe incluir solo el detalle que realmente cambia el resultado.

  1. Las notas completas o la transcripción
  2. El objetivo de la reunión
  3. Los campos necesarios: tarea, responsable, fecha y estado
  4. La forma de marcar información ausente
  5. Si deben incluirse decisiones y asuntos pendientes

Prompt listo para usar

Sustituye el texto entre corchetes por tu situación. Elimina o anonimiza la información confidencial y verifica el resultado con la fuente antes de utilizarlo.

Prompt listo para usar
Organiza las siguientes notas de reunión para facilitar el seguimiento.
Objetivo: que los participantes confirmen rápidamente las decisiones y las próximas acciones.
Secciones de salida:
1. Resumen breve
2. Decisiones
3. Tabla de tareas: acción, responsable, fecha límite y prioridad
4. Asuntos pendientes

Utiliza únicamente las notas. Si falta un responsable o una fecha, escribe “Sin confirmar” en lugar de suponerlo. Agrupa tareas duplicadas sin eliminar contexto importante.

Ejemplo: Preparar el lanzamiento de un nuevo servicio

El lanzamiento será el 20 de agosto. Tanaka actualizará la página de ayuda antes del 15. Las pruebas deben terminar el 18, pero no hay responsable. La fecha del aviso a clientes sigue pendiente.

Resumen: El equipo confirmó la fecha de lanzamiento y varias tareas previas.

Decisiones: Lanzamiento el 20 de agosto. Actualizar la página de ayuda antes de publicar.

Tareas: Actualizar página — Tanaka — 15 de agosto. Completar pruebas — Responsable sin confirmar — 18 de agosto.

Pendiente: Decidir cuándo enviar el aviso a clientes.

Cómo adaptar el prompt a otras situaciones

La estructura principal se mantiene, pero los hechos, el público y el formato deben cambiar según la tarea.

Crear un correo de seguimiento

Convierte las decisiones y tareas asignadas en un mensaje breve para los participantes.

Preparar la próxima agenda

Utiliza preguntas abiertas y tareas atrasadas como puntos del orden del día.

Proponer prioridades

Ordena tareas solo cuando existan datos suficientes sobre impacto y plazo, y marca la prioridad como propuesta.

Qué revisar antes de usar el resultado

Un texto bien redactado todavía puede incluir un dato incorrecto o un compromiso inadecuado. Revisa estos puntos antes de compartirlo.

  • Cada tarea está respaldada por las notas.
  • No se han inventado responsables ni fechas.
  • Las decisiones no se mezclan con propuestas.
  • La agrupación de duplicados no oculta responsabilidades distintas.
  • Las notas originales siguen disponibles para consultar el contexto.

Preguntas frecuentes

¿Puede ChatGPT deducir el responsable por la conversación?

Puede extraer un responsable asignado de forma explícita. Si solo se insinúa, conviene marcarlo como sin confirmar.

¿Debo pegar toda la transcripción?

Puedes hacerlo, pero elimina datos personales o confidenciales innecesarios y divide transcripciones muy largas por secciones.

¿Cómo combino varias reuniones sobre el mismo proyecto?

Indica la fecha y la fuente de cada nota y pide que se separen las decisiones actuales de las anteriores.

¿Puede actualizar automáticamente una herramienta de proyectos?

No mediante este prompt por sí solo. Revisa primero las tareas y copia después las aprobadas en la herramienta del equipo.
