Toybird Labs Blog parte de problemas cotidianos del trabajo y el estudio. A partir de ahí propone una forma práctica de cambiar el proceso; el producto aparece al final como una posible implementación.

Si una cifra, condición o párrafo desaparece al desplazarte o cambiar de ventana, una Reference View mantiene visible solo la información que consultas repetidamente mientras la tarea principal sigue ocupando el centro.

Shared Attention

Compartir pantalla y mostrar dónde mirar | Shared Attention

Tú sabes dónde estás mirando; la audiencia no. Shared Attention alinea lo que dices, el lugar que deben mirar, la acción y el resultado visible para que todos sigan el mismo punto de la pantalla.
