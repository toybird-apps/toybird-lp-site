Cómo hacer que ChatGPT pida la información que falta

Utiliza prompts para que ChatGPT pida información ausente una pregunta cada vez, en una lista breve o mediante opciones.

3 de agosto de 20268 min de lecturaMasaki Iino

A veces lo más difícil no es escribir el prompt, sino saber qué datos son importantes. Puedes pedir a ChatGPT que se detenga, detecte los vacíos y te pregunte antes de redactar la respuesta final.

Al final tendrás un prompt reutilizable, un ejemplo completo y una lista breve para revisar el resultado antes de usarlo en el trabajo.

Lo que podrás hacer

  • Indica que no debe suponer datos esenciales.
  • Decide si debe preguntar de uno en uno o en una lista corta.
  • Limita las preguntas a la información que realmente cambia el resultado.
  • Confirma las condiciones reunidas antes de pedir el texto final.

Por qué una instrucción breve suele quedarse corta

Una instrucción breve como «Ayúdame a redactar un anuncio.» puede generar un texto correcto, pero no explica el contexto, el destinatario, los límites ni el formato. ChatGPT debe completar esos vacíos y puede producir frases genéricas o suposiciones no respaldadas.

Qué conviene indicar antes de pedir la respuesta

Antes de pedir la respuesta final, prepara la información siguiente. No hace falta escribir un prompt largo; cada elemento debe incluir solo el detalle que realmente cambia el resultado.

  1. La tarea que quieres completar
  2. La información que ya conoces
  3. Los aspectos sobre los que no debe hacer suposiciones
  4. El número máximo de preguntas
  5. El momento en que debe pasar de preguntar a redactar

Prompt listo para usar

Sustituye el texto entre corchetes por tu situación. Elimina o anonimiza la información confidencial y verifica el resultado con la fuente antes de utilizarlo.

Prompt listo para usar
Quiero completar la siguiente tarea: [tarea].
Información conocida: [hechos disponibles]
No hagas suposiciones sobre: [fechas, público, política, presupuesto, etc.]

Antes de redactar, identifica la información ausente que podría cambiar el resultado. Hazme una pregunta cada vez y no superes cinco preguntas. Cuando dispongas de lo necesario, resume las condiciones acordadas y espera mi aprobación antes de redactar.

Ejemplo: Preparar un anuncio para clientes

Sabes que se publicará una función, pero todavía no has definido el público, la fecha, la acción requerida ni el contacto de soporte.

Pregunta 1: ¿Quién debe recibir el anuncio: todos los clientes, solo administradores o usuarios de un plan concreto?

Pregunta 2: ¿La fecha de lanzamiento está confirmada y debe incluirse la zona horaria?

Pregunta 3: ¿El cliente debe realizar alguna acción antes o después del lanzamiento?

Cómo adaptar el prompt a otras situaciones

La estructura principal se mantiene, pero los hechos, el público y el formato deben cambiar según la tarea.

Una pregunta cada vez

Adecuado cuando la tarea es nueva y cada respuesta puede cambiar la siguiente pregunta.

Máximo tres preguntas

Útil cuando se necesita avanzar rápido y solo importan los vacíos de mayor impacto.

Proponer opciones

Pide dos o tres alternativas cuando no conoces la terminología o el formato preferido.

Qué revisar antes de usar el resultado

Un texto bien redactado todavía puede incluir un dato incorrecto o un compromiso inadecuado. Revisa estos puntos antes de compartirlo.

  • Las preguntas se centran en datos que cambian la salida.
  • No se solicita información confidencial sin necesidad.
  • El número de preguntas sigue siendo manejable.
  • Las condiciones finales se resumen antes de redactar.
  • Puedes detener las preguntas y solicitar un borrador provisional cuando sea necesario.

Preguntas frecuentes

¿ChatGPT preguntará siempre si añado esta instrucción?

Normalmente sí, pero conviene indicar que debe esperar tus respuestas antes de redactar.

¿Puedo pedir varias preguntas a la vez?

Sí. Solicita una lista numerada y establece un máximo, por ejemplo tres.

¿Qué hago si no conozco la respuesta?

Pide que presente opciones y explique cómo cambiaría el resultado con cada una.

¿Cuándo no merece la pena usar preguntas aclaratorias?

En una transformación sencilla con todo el material disponible, una instrucción directa suele ser más rápida.
