# Published-site layout

This is the source for https://lp.toybird.com/. `README.md` describes the current publishing and verification workflow.

## Product landing pages

- AI Study Sheet: Japanese root path plus English, Korean, and Simplified Chinese.
- Pocket Screen, Prompt Ready, Pointer Cue: Japanese root paths plus English.
- KoeSub: Japanese.
- Additional language aliases redirect to supported LPs; preserve those URLs and canonical targets.

## Other content

- English portfolio homepage.
- Japanese and translated blog collections.
- Shared locale code, analytics instrumentation, badges, and versioned media.
- Canonical sitemap, robots.txt, domain/search verification files, and IndexNow key.

## Maintenance boundary

`apps/` product documentation is in the separate `toybird-apps-site` repository at https://labs.toybird.com/. Do not replace either repository with an old release ZIP or historical partial-site manifest.
