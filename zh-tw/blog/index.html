Recall Layer

持續加入教材，保留原始版面反覆複習

從照片與PDF的自動遮罩開始，搭配Auto、建議複習與提醒，讓新增教材持續進入日常複習。

Recall Layer

學習資料在哪裡處理：把本機辨識、購買、匯出與備份分開看

照片、PDF、學習紀錄、建議複習與通知各自怎麼使用？配合 v4.1 的學習流程，區分本機教材處理、App Store 購買、主動分享與備份。

Recall Layer

會考、學測與國考複習｜持續加入自己的講義與 PDF

逐步加入學過的照片與 PDF，在短時間使用 Auto 和建議複習，再回到原始講義與習題確認理解。

Recall Layer

用教材照片與 PDF 複習｜從原始頁面到 Auto 學習

匯入現有講義，保留圖表與上下文，使用 Auto 回想答案。教材增加後，透過建議複習回到已儲存的內容，不必重做整套卡片。

Reference View

在單一 Mac 螢幕工作而不失去參考資訊 | Reference View

把清楚的參考資料留在文件旁，完成比較時不必反覆切回原文。將Pocket Screen的Focus View、Freeze與多個檢視放進同一個讀寫流程。

Shared Attention

螢幕分享時，把「看哪裡」也一起說清楚

讓講解、目標、操作與可見結果保持同一節奏。

Shared Attention

螢幕分享時告訴對方該看哪裡 | Shared Attention

指出控制項、完成點擊，再讓觀眾看見結果。把Pointer Cue的免費提示與Pro範圍強調，放進一次具體的螢幕分享示範。
