先討論使用方式，再介紹產品

Toybird Labs Blog 從實際工作與學習中的「常常遇到」出發，先整理一種更順手的工作流程。產品只在最後作為實現這種方式的一種選擇出現。

  • 用 Recall Layer 替既有教材增加「作答」步驟
  • 用 Reference View 把需要的資訊留在眼前
  • 用 Shared Attention 在螢幕分享中同步觀看位置

Recall Layer

不重做教材，也能把它變成「需要作答」的材料

保留原頁面，只增加遮住、作答、核對這一層。

Recall Layer

學習資料在哪裡處理：把本機辨識、購買、匯出與備份分開看

「在裝置內處理」不等於「每個操作永遠不連網」。確認教材的隱私範圍，要分別追蹤辨識、儲存、購買和自己主動分享的路徑。

Recall Layer

用自己的PDF與講義準備會考、學測或國考：一週複習安排範例

教材存進手機後，還要決定哪頁用來背、哪頁用來理解、哪頁必須實際作答。把錯誤連回原始說明，避免資料整理完了卻沒有檢驗理解。

Recall Layer

用現有教材做主動回想｜不用重做卡片的 Recall Layer

教材已經存在，不必先重做成一套卡片。Recall Layer 是在原頁面上增加「遮住 → 作答 → 核對」，把閱讀材料變成可以主動回答的複習材料。

Reference View

讓需要的資訊不要在工作中消失

把主工作與反覆查看的小塊參考資訊分開。

Reference View

在單一 Mac 螢幕工作而不失去參考資訊 | Reference View

捲動 SaaS 頁面或切換視窗後，如果數字、條件或段落總是從眼前消失，可以用 Reference View 只保留反覆查看的資訊，同時讓主工作維持在中心。

Shared Attention

螢幕分享時，把「看哪裡」也一起說清楚

讓講解、目標、操作與可見結果保持同一節奏。

Shared Attention

螢幕分享時告訴對方該看哪裡 | Shared Attention

你知道自己正在看哪裡，但觀看者不知道。Shared Attention 把講解、觀看位置、操作與可見結果放在同一條流程，讓雙方關注同一個位置。
