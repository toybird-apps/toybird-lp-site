螢幕分享時如何引導注意力：指標、框選與作用中視窗

依照觀眾需要看到的內容選擇提示方式

依目標大小選擇提示，需要長時間保留的標記則使用會議註解。

方法適用情境注意事項
放慢移動並在目標處停頓不安裝額外工具的短講解操作較快時觀眾仍可能跟不上
需要時才顯示指標強調環遠端會議、產品示範與培訓示範前應在分享預覽中確認效果
用臨時邊框標出一個區域表格、設定面板與輸入區域不能取代自由繪製與文字註解
保持作用中視窗明亮並調暗其他區域需要在多個應用程式間切換的示範判斷顏色與設計時應降低調暗程度
使用會議應用程式的註解工具需要保留線條或文字的講解切換工具可能打斷講解節奏

在下一次螢幕分享中按這個順序操作

  1. 減少螢幕上的無關資訊
    暫停通知、關閉不用的視窗，並移除私人資訊。
  2. 檢查系統指標設定
    在 macOS 或 Windows 中調整大小與顏色，避免指標融入分享內容。
  3. 先說明目的，再指出位置
    先說明動作，再說明位置：「我們要關閉通知。請看右上角的設定。」
  4. 針對點、區域與視窗使用不同提示
    按鈕用強調環，表格或設定區域用框線，目前應用程式用作用中視窗強調。
  5. 透過分享預覽與短錄影確認效果
    應檢查觀眾實際收到的畫面；縮放或壓縮後，強調環、框線與調暗效果可能不同。

  • 提示只短暫顯示，避免遮住正在說明的內容
  • 更換顯示器、Stage Manager 或分享應用後重新測試

常見問題

何時用強調環，何時用框選？

按鈕、圖示、點擊位置用強調環；表格欄、設定面板、輸入區域用框選。

會議應用程式的註解功能不夠嗎？

註解適合保留線條與文字；若只是短暫提示後立即繼續操作，鍵盤觸發的強調環或框選更順暢。

何時使用作用中視窗強調？

在多應用程式示範中，先用它說明應關注哪個應用程式，再用強調環或框選指出具體位置。
