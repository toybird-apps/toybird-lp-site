用于真实任务

先从已有的可信来源开始，例如邮件记录、会议纪要、讲义、PDF 或系统页面，而不是再增加一层笔记。

通过为不同目标匹配不同提示，让屏幕共享更易理解：控件用指针、区域用框选、当前应用用活动窗口强调。

根据观众需要看到的内容选择提示方式

根据目标大小选择提示，需要长期保留的标记则使用会议批注。

方法适用场景注意点
放慢移动并在目标处停顿不安装额外工具的短讲解操作较快时观众仍可能跟不上
需要时才显示指针强调环远程会议、产品演示和培训演示前应在共享预览中确认效果
用临时边框标出一个区域表格、设置面板和输入区域不能替代自由绘制和文字批注
保持活动窗口明亮并调暗其余区域需要在多个应用之间切换的演示判断颜色和设计时应降低调暗程度
使用会议应用的批注工具需要保留线条或文字的讲解切换工具可能打断讲解节奏

在下一次屏幕共享中按这个顺序操作

  1. 减少屏幕上的无关信息
    暂停通知、关闭不用的窗口，并移除隐私信息。
  2. 检查系统指针设置
    在 macOS 或 Windows 中调整大小和颜色，避免指针融入共享内容。
  3. 先说明目的，再指出位置
    先说明动作，再说明位置：“我们要关闭通知。请看右上角的设置。”
  4. 针对点、区域和窗口使用不同提示
    按钮用强调环，表格或设置区域用边框，当前应用用活动窗口强调。
  5. 通过共享预览和短录屏确认效果
    应检查观众实际收到的画面；缩放或压缩后，强调环、边框和调暗效果可能不同。

使用前需要了解的事项

需要长期保留手绘、箭头或文字时，应使用会议批注或专用绘图工具。

Focus Cue 仅限 macOS；Windows 主要使用强调环和临时边框。

Pointer Cue 不是完整的屏幕批注套件，而是专注于指示、框选区域和突出当前窗口。叠加效果在设备本地运行，不截取屏幕或提取文字。

常见问题

何时用强调环，何时用框选？

按钮、图标、点击位置用强调环；表格列、设置面板、输入区域用框选。

会议应用的批注功能不够吗？

批注适合保留线条和文字；若只是短暂提示后立即继续操作，键盘触发的强调环或框选更顺畅。

何时使用活动窗口强调？

在多应用演示中，先用它说明应关注哪个应用，再用强调环或框选指出具体位置。
