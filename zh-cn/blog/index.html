先讨论使用方式，再介绍产品

Toybird Labs Blog 从实际工作和学习中的“经常遇到”出发，先整理一种更顺手的工作流。产品只在最后作为实现这种方式的一种选择出现。

  • 用 Recall Layer 给已有教材增加“回答”步骤
  • 用 Reference View 把需要的信息留在眼前
  • 用 Shared Attention 在屏幕共享中同步观看位置

Recall Layer

不重做教材，也能把它变成“需要回答”的材料

保留原页面，只增加遮住、回答、核对这一层。

Recall Layer

学习资料在哪里处理：把本地识别、购买、导出和备份分开看

“在设备上处理”与“所有操作永远不联网”不是同一句话。判断教材的隐私边界，要逐项看识别、保存、购买和自己主动分享的流程。

Recall Layer

用现有教材做主动回忆｜不必重做卡片的 Recall Layer

教材已经存在，不必先重做成一套卡片。Recall Layer是在原页面上增加“遮住 → 回答 → 核对”，把阅读材料变成可以主动回答的复习材料。

Recall Layer

用自己的讲义和 PDF 准备高考、考研或期末：一周复习安排实例

资料存进手机后，还需要决定哪页用来背、哪页用来理解、哪页必须动笔做题。把具体错误与原讲义连起来，才能避免只整理资料、不检验学习。

Reference View

让需要的信息不要在工作中消失

把主任务和反复查看的小块参考信息分开。

Reference View

在一个 Mac 屏幕上工作而不丢失参考信息 | Reference View

滚动 SaaS 页面或切换窗口后，如果数字、条件或段落总是从眼前消失，可以用 Reference View 只保留反复查看的信息，同时让主任务保持在中心。

Shared Attention

屏幕共享时，把“看哪里”也一起说清楚

让讲解、目标、操作和可见结果保持同一节奏。

Shared Attention

屏幕共享时告诉对方该看哪里 | Shared Attention

你知道自己正在看哪里，但观看者不知道。Shared Attention 把讲解、观看位置、操作和可见结果放进同一条流程，让双方关注同一个位置。
