Recall Layer

不断加入教材，保留原始版面反复复习

从照片和PDF的自动遮罩开始，结合Auto、推荐复习和提醒，让新增的教材继续进入日常复习。

Recall Layer

学习资料在哪里处理：把本地识别、购买、导出和备份分开看

照片、PDF、学习记录、推荐复习与通知分别怎样使用？结合 v4.1 的学习流程，区分本地教材处理、App Store 购买、主动分享与备份。

Recall Layer

用教材照片和 PDF 复习｜从原始页面到 Auto 学习

导入已有讲义，保留图表和上下文，用 Auto 回忆答案。资料增加后，通过推荐复习回到已经保存的内容，无须重新制作整套卡片。

Recall Layer

高考、考研与期末复习｜持续添加自己的讲义和 PDF

把学过的照片和 PDF 逐步加入资料库，在短时间内使用 Auto 和推荐复习，再回到原始讲义与习题中检查理解。

Reference View

让需要的信息不要在工作中消失

把主任务和反复查看的小块参考信息分开。

Reference View

在一个 Mac 屏幕上工作而不丢失参考信息 | Reference View

把清晰的参考资料留在文档旁，完成比较时不必反复切回原文。将Pocket Screen的Focus View、Freeze和多个视图放进同一个读写流程。

Shared Attention

屏幕共享时，把“看哪里”也一起说清楚

让讲解、目标、操作和可见结果保持同一节奏。

Shared Attention

屏幕共享时告诉对方该看哪里 | Shared Attention

指出控件、完成点击，再让观众看见结果。把Pointer Cue的免费提示和Pro范围强调，放进一次具体的屏幕共享演示。
