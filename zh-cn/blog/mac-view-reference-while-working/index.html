用于真实任务

根据任务选择合适的显示方式

根据查看频率以及两个应用是否需要同等空间来选择。

方法适用场景注意点
将两个窗口平铺两个应用同样重要的任务两个窗口都可能变得过窄
把应用放在同一个 Stage Manager 组中成组切换相关应用单屏空间可能比较紧张
使用全屏或单独的 Space以长时间阅读为主的任务每次查看资料都要离开主工作应用
让小型参考窗口持续可见每隔几秒就要核对细节的任务需要调整到合适的大小和位置

按步骤设置一项真实任务

  1. 确定主要任务
    把大部分屏幕留给文档、邮件、表格等主要工作应用。
  2. 按查看频率分类
    判断参考资料是只看一次、每几分钟查看，还是每几秒查看。
  3. 匹配显示方式
    两者同等重要时用平铺，第二个应用主要用于核对时用小型参考窗。
  4. 检查可读性
    把参考窗调到无需频繁缩放就能看清数字、专有名词和步骤的大小。
  5. 完成后清理布局
    关闭已经不需要的参考资料，避免把视觉杂乱带到下一个任务。

常见问题

只有一块 MacBook 屏幕也能提高效率吗？

可以。让主任务保持足够大，只留下经常查看的参考资料，即使没有第二显示器也能减少切换。

何时用 Split View，何时用浮动参考窗？

两个应用都需要同等操作时用 Split View；一个是主应用、另一个主要用于查看时用浮动参考窗。

有外接显示器时也有用吗？

第二显示器能提供更大空间，但在移动办公、希望减少视线移动或需要让某个细节始终置顶时，浮动参考窗仍然有用。
