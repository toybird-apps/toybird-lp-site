# 把教材照片变成遮挡自测：先完成一张能答对也能纠错的复习页
拍清楚教材只是第一步。真正的自测还要决定：隐藏什么答案、留下什么线索，以及答错后回到哪里核对。

下面的水循环小教材根据 USGS 的说明编写，题目和版式由本文设计。它不是应用自动识别的实测截图，也不代表考试的全部范围。

## 先准备可以核对的原始材料
| 编号 | 术语 | 解释 |
| R1 | 蒸发 | 液态水变成水蒸气。 |
| R2 | 凝结 | 水蒸气变成液态水；细小水滴可以形成云。 |
| R3 | 降水 | 水从云中落下，例如雨或雪。 |

这页要区分的是“状态变化”和“从云中落下”，而不只是记住三个名词。把凝结答成降水时，应对照 R2 和 R3。依据：[USGS 凝结说明](https://www.usgs.gov/water-science-school/science/condensation-and-water-cycle)、[USGS 降水说明](https://www.usgs.gov/water-science-school/science/precipitation-and-water-cycle)。

## 遮住答案，但不要连问题一起遮住
| 保留的内容 | 遮住的答案 | 想确认的理解 |
| 液态水变成水蒸气 | 蒸发 | 状态变化的名称 |
| 水蒸气变成液态水 | 凝结 | 与蒸发方向相反 |
| 水从云中以雨或雪等形式落下 | 降水 | 形成水滴与落下的区别 |

如果连解释一起盖住，就没有可回答的问题。如果旁边标题还写着同一个词，学习者可能只是在找答案。检查标题、图注和页边提示，再判断遮挡是否合适。

## 放到 iPhone 上复习时，先检查一页
在 AI背书卡（AI Study Sheet）中拍摄教材，或选择照片、PDF。普通模式下先查看建议的遮挡，再用现有编辑功能调整。使用教材原有红色、橙色标记的模式，编辑范围与普通模式不同，不要假定所有遮挡都能以同样方式修改。

## 按错误的性质决定下一步
| 看到的情况 | 下一步 |
| 术语正确，也能解释 | 隔一段时间再测，不必只立即重复同一个词 |
| 把凝结答成降水 | 回到 R2/R3，说明两种过程分别发生了什么 |
| 答案仍留在标题里 | 修正遮挡，再判断是否真的记住 |
| 照片中的字读不清 | 先换图，不把输入质量问题当成记忆错误 |
| 展开后仍不理解解释 | 回到阅读或做题，而不是继续增加遮挡 |

第一张合格复习页的标准不是遮得多，而是有三个能回答的问题，以及从错误返回解释的短路径。应用可以帮助重复使用手里的教材，但不会替你确定所有考试重点。

# 用自己的讲义和 PDF 准备高考、考研或期末：一周复习安排实例
资料存进手机后，还需要决定哪页用来背、哪页用来理解、哪页必须动笔做题。把具体错误与原讲义连起来，才能避免只整理资料、不检验学习。

以下六页资料和七天安排是虚构的教学例子，应按实际课程和考试要求调整，不是官方备考时间表，也不是对所有人最优的复习间隔。

## 给每一页不同的任务
| 页码 | 内容 | 用法 |
| P1 | 三个概念的定义 | 回忆关键词 |
| P2 | 一个过程图 | 解释箭头和关系 |
| P3 | 易混概念比较表 | 说出区别 |
| P4 | 练习题 | 按原题形式完整作答 |
| P5 | 解析 | 找到错误的理由 |
| P6 | P1的重复扫描 | 不重复加入复习任务 |

高考材料中的图表解读、考研或期末中的推导和论述，都不能简单替换成辨认隐藏词。先保留这些原有任务，再决定哪些知识适合用短时回忆补充。

## 让资料名指向错误的来源
“第三章—过程—P2”比“照片48”更容易定位。在标题或备注中保留原页码、主题和来源；文件夹负责归类，页码负责把某个错题带回准确位置。

图片用于说明资料库界面，里面不是本文虚构的 P1—P6资料。无需为了展示新例子而改写应用截图。

## 第一周，把回忆和做题安排在一起
| 天数 | 工作 | 留下的记录 |
| 第1天 | 阅读P1—P3，准备少量明确问题 | 原页码和不合适的遮挡 |
| 第2天 | 回答P1，解释P2 | 具体混淆，而不只是错了几题 |
| 第3天 | 对比P3，并复查前一天错误 | 为什么两个概念不同 |
| 第4天 | 按原形式完成P4 | 每个错题对应P1—P3或P5 |
| 第5天 | 回到对应解释 | 用一句话说明改正原因 |
| 第6天 | 换一道相同薄弱点的新题 | 能否离开原页应用知识 |
| 第7天 | 检查未解决的问题 | 下一周的小目标清单 |

## 漏掉一天，不必把第二天的任务全部翻倍
假设 E1 是P1的词想不起来，E2是P2的箭头方向解释错了。E1可以用术语提问检查，E2则要重新解释图。只打开同一个标签，并不能确认理解是否改变。

如果第三天没完成，保留第四天的一次实际做题，再选最影响解题的两个错误回看。已经掌握的词可以延后复查。这样改计划，是为了保持可执行，而不是声称某个固定天数适合所有学习者。

## 用应用组织可重复的部分
在 AI背书卡中导入选好的照片或PDF，检查遮挡后保存，通过文件夹或搜索确定学习范围。顺序适合沿过程回看，随机能检验是否依赖页序，弱项优先便于回到记录的困难。选择能完成的题量，而不是只选最大的数字。

应用成绩不等于掌握整个学科。计算、作文、材料解读和新题仍要独立练习。一周结束时，你应能说明：下一次看哪页、为了纠正什么错误、用哪一道题验证理解。

# 学习资料在哪里处理：把本地识别、购买、导出和备份分开看
“在设备上处理”与“所有操作永远不联网”不是同一句话。判断教材的隐私边界，要逐项看识别、保存、购买和自己主动分享的流程。

本文依据 Toybird Labs 的 AI Study Sheet 隐私说明和使用说明整理，不是网络流量审计，也不以断网时能打开应用作为“从不通信”的证据。

## 先区分四种数据路径
| 操作 | 涉及的信息 | 说明中的处理边界 |
| 导入、识别、遮挡与学习记录 | 教材图像、PDF、识别文字、遮挡、记录 | 在设备内处理和保存，不将教材发送至外部AI或开发者服务器 |
| 购买及恢复购买 | App Store购买状态 | 使用Apple的商店和StoreKit服务，可能与Apple通信 |
| 主动导出或分享 | 导出的备份或图像 | 用户选择的目标应用或服务接收文件，适用其规则 |
| 系统或设备备份 | 备份设置所涵盖的数据 | 取决于iOS和用户选择的云服务，不等同于应用自动同步 |

原始说明可在[官方隐私政策](https://labs.toybird.com/apps/ai-memorize-sheet/privacy.html)和[使用说明](https://labs.toybird.com/apps/ai-memorize-sheet/support.html)中查看。功能变化时，应重新核对这些来源，而不是只看一张“离线”宣传图。

## 用一张自制教材走完检查
准备一页只有虚构内容的练习纸，例如“示例班级：A组；题目：水循环”。拍摄或选择本地文件，确认应用内的识别、遮挡和保存方式。这个过程能验证功能是否可用，但单次观察不能证明所有通信行为。

接着分别检查：是否主动执行了分享，文件保存到哪里，设备是否开启相关云备份。不要用真实姓名、成绩单或未获准传播的资料来测试。

## 断网测试能说明什么，不能说明什么
| 观察 | 可以说明 | 不能直接说明 |
| 断网仍能查看已保存教材 | 这项本地操作当时可用 | 每一种功能都不会联网 |
| 未要求建立开发者账户 | 当前流程不需要该账户 | 系统备份和其他服务都没有副本 |
| 分享界面选择了云盘 | 用户选择把文件交给该服务 | 云盘的保留和删除规则与应用相同 |
| 删除应用内页面 | 本地页面被移除 | 以前导出的备份和别人收到的文件也被删除 |

结论要与实际观察同样窄。想验证网络行为本身，需要相应的记录和分析，不能从“识别成功”跳到“绝对安全”。

## 导出前多做一次内容选择
假设资料左上角有学生姓名，正文有课堂题目。练习只需要正文时，可以先用合法、合适的方式准备不含姓名的副本。若自己选择把原文件发送到云盘或聊天软件，便跨出了原来设备内处理的边界。

下面是一份导出前检查表：收件人是否正确；是否包含不必要的个人信息；是否有权分享教材；保存位置是否合适；以后删除哪些副本。它用于整理自己的操作，不替代学校或单位的数据规则。

## 备份与同步不是一回事
应用提供用户主动导出的备份，并不等于持续自动云同步。更换设备前应按官方使用说明准备、保存并验证备份；在新设备确认需要的数据存在之前，不要先删除唯一原件。已经导出到其他位置的文件，需要在对应位置管理。

隐私判断的成果不是一句“完全不联网”，而是一张说得清楚的数据路径表：哪些留在设备上，哪些因购买通信，哪些因为自己的操作离开设备。AI背书卡的本地教材处理与用户主动使用其他服务，应始终分开描述。

# 在一个 Mac 屏幕上工作：把必要的参考资料留在眼前
主要任务在一个窗口里完成时，偶尔查阅的文档不一定需要占一半屏幕。小型参考视图可以留下必要的几行，同时保留主任务的工作面积。

用同一项任务选择布局。下面的规格表和判断便笺是虚构教材，不是计时后的效率比较。

## 从三个选项写出判断便笺
需要两周内交付、至少一年保修的部件。价格是任意示例单位。

| 选项 | 交付 | 示例价格 | 保修 |
| A | 2周 | 120 | 1年 |
| B | 3周 | 100 | 2年 |
| C | 未确认 | 90 | 未确认 |

便笺应指出A满足两项条件、B超过期限、C需要补问。只留下价格列会丢掉判断依据，因此行内容和列标题要一起可见。

## 根据两个窗口的操作频率选择
| 工作方式 | 先考虑的布局 | 理由 |
| 不断编辑来源和便笺 | 普通窗口并排 | 两边都需要可操作面积 |
| 主要写便笺，偶尔查几行 | 主窗口加小参考视图 | 把空间留给主任务 |
| 理解完整图或密集表格 | 更大的原窗口或分屏 | 可读性和完整语境优先 |

macOS提供窗口平铺和Split View等方式，具体操作随系统版本变化，可参考[Apple窗口说明](https://support.apple.com/guide/mac-help/tile-app-windows-mchlef287e5d/mac)。浮动参考是一种补充，不需要在所有场景都替代系统功能。

## 让小视图保留上下文
打开原资料和便笺，在Pocket Screen中选择来源窗口，留下相关行与标题，再回到写作。视图不要压在当前输入行或重要按钮上。如果必须反复放大才能阅读，就应该给原资料更大空间，而不是坚持最小窗口。

其价值不是“所有东西都置顶”，而是在继续主任务时，仍能看到判断所需的部分。

## 分清实时状态与保留的状态
需要知道来源当前情况时使用实时参照。冻结的视图用于留住某一时刻，不会自动反映其后的修改。作出最终决定前，应回到原资料确认条件是否变化。

一个浏览器窗口的演示，不代表所有标签页都能同时独立实时捕获。使用已安装公开版本的功能，不把未来版本的演示当成已经提供的功能。

## 最后的便笺仍要回原表核对
> A满足两周交付和一年保修。B保修更长，但不满足交期。C需要确认交付与保修后，才能作为合格选项比较。

小视图帮助取用信息，不保证信息仍是最新或判断一定正确。屏幕共享前，还要用无敏感内容的资料检查对方实际收到的画面。这篇文章展示布局和判断过程，不主张测得了时间节省率或所有环境中的共享排除效果。

# 屏幕共享怎么讲得清楚：一个30秒操作演示脚本
指针在移动，不代表观众知道按钮为什么重要。把讲解、目标、操作和结果连起来，观众才不必猜刚刚发生了什么。

下面是虚构练习界面：“即时通知”和“每周摘要”都已开启。任务是只关闭即时通知。时间段是排练用的安排，不是实验得出的最佳时长。

## 点击前，先讲最终要达到什么
重点不是“我点了这里”，而是“即时通知关闭，每周摘要保持开启”。

| 时间 | 说什么 | 做什么 | 提示方式 |
| 0—5秒 | 关闭即时通知，保留每周摘要 | 保持两项可见 | 先不用额外标记 |
| 5—10秒 | 这里是即时通知的开关 | 指针移到标签和控件 | 短暂指针强调 |
| 10—16秒 | 这两个设置是独立的 | 展示两行的关系 | 有需要时短暂框选范围 |
| 16—22秒 | 只关闭这一项 | 点击第一个开关一次 | 稳定地展示操作 |
| 22—30秒 | 即时已关，每周仍开 | 停留在最终状态 | 不用新动画抢走注意 |

## 点用于定位，范围用于解释关系
指针回答“哪个按钮”，范围回答“哪几行属于这段解释”。两者都不能替代可读的文字或一句关于目的的说明。只讲一个开关却高亮整页，可能反而让目标不清楚。

Pointer Cue可在Mac上提供临时指针和范围强调，具体使用已安装版本设置的手势。需要把箭头长期留在画面上时，绘图工具解决的是另一种任务，不必把临时提示勉强用成标注。

## 操作后把结果说出来
明确说出两项最终状态，并停留片刻，比“大家可以看到”更具体。同一脚本可以先不加提示排练一次，再加点或范围提示一次，观察目标和结果是否容易识别，而不是数用了多少效果。

## 也要检查接收端
远程演示应使用无敏感内容，查看参与者实际收到的画面。小字和细线在捕获、传输后可能不同。本地产品视频不是接收端画质测试。

产品视频中对网站的操作可以解释提示形式，却不是上面虚构通知界面的执行记录。预发布视频也不能自动证明正式版本的全部功能或提供条件。

## 改成你自己的下一个演示
选一个不含机密的真实任务，写下前后状态，选择一处提示确实增加信息的位置，然后练习操作后的停顿。需要临时标记支持讲解时使用Pointer Cue；结果本来就清晰时，让界面自己说明即可。
