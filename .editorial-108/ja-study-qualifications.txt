# ITパスポートの略語を利用場面で覚える｜SaaS・PaaS・IaaSを3問で見分ける
略語の日本語訳を言えても、問題文で誰が何を管理するかを取り違えると選べません。三つのクラウドサービスを、受け取るもの・自分が管理するもの・使う場面の同じ軸で比べます。

以下の会社と依頼は自作の学習ケースです。実際の試験問題や製品比較ではありません。定義の根拠には[NIST SP 800-145](https://csrc.nist.gov/pubs/sp/800/145/final)を使い、試験範囲は受験時点の[IPAのシラバス](https://www.ipa.go.jp/shiken/syllabus/gaiyou.html)で確認してください。

## 「使う・作る・組む」を管理範囲とつなぐ
| サービス | 受け取るもの | 利用者が主に扱うもの | 覚える入口 |
| SaaS | 提供者の完成したアプリケーション | 利用データや許された個別設定 | アプリを使う |
| PaaS | アプリを配置・実行するための基盤 | 自分のアプリとデータ、許された実行環境設定 | アプリを作って動かす |
| IaaS | 計算・保存・ネットワーク等の基礎リソース | OS、アプリ、データなど | 必要な環境を組む |

「使う・作る・組む」は記憶の補助です。単語だけで判定せず、OSまで利用者が管理するのか、提供された基盤にアプリを載せるのかを問題文で確かめます。現実のサービスは複数の提供形態を持つことがあるため、会社名だけで分類しないでください。

## 同じ会社の三つの依頼を読み分ける
| 依頼 | 決め手になる条件 | 回答 |
| A：メールを使いたい。提供済みアプリにログインし、利用者設定を変える | 完成したアプリを利用 | SaaS |
| B：自作アプリを動かしたい。OSは提供者が管理する実行基盤へ配置する | 自作アプリを管理するが基盤のOSは管理しない | PaaS |
| C：仮想サーバーを使い、OSとミドルウェアも選んで管理する | OSから管理する基礎リソースを利用 | IaaS |

これは分類する条件を絞った架空例です。Aの「インターネットを使う」だけ、Bの「アプリ」だけ、といった一語では見分けられません。

## マスクはサービス名から始め、次に管理範囲を問う
最初の回は、表の依頼と条件を残し、回答だけを隠します。次の回はサービス名を見せ、「利用者は何を管理するか」を説明します。同じ表を別の向きから答えることで、行の位置だけに頼らない確認になります。

| 二回目の問い | 答えに含めたいこと |
| SaaSとPaaSは何が違う？ | 完成アプリを使うか、自分のアプリを提供基盤へ配置するか |
| PaaSをIaaSと答えた原因は？ | アプリの管理とOSの管理を同じものとして読んだ可能性 |
| IaaSなら物理基盤もすべて自社管理？ | いいえ。基礎リソースを利用してOS等を管理することと、提供者側の物理基盤管理は別 |

## 他の略語にも、四つの欄を使う
| 比較軸 | 確認すること |
| 目的 | 何を解決・管理・保護するか |
| 対象 | 人・情報・システム・業務のどれか |
| タイミング | 計画・開発・運用・監査などのどこで使うか |
| 具体例 | 条件を絞った業務のどこへ当てはまるか |

正式名称だけのカードを増やす前に、似た言葉と何が違うかを一行加えます。用語が何の分野にあるかはシラバスへ戻して確認し、古い用語一覧を最新の試験範囲だと扱わないようにします。

## 誤答から、問題の条件へ戻る
「BをIaaSと回答／OSを誰が管理するか読み落とした」と記録したら、次回はBだけでなくCも読み、管理者の違いを説明します。正しい名称を見て終わるのではなく、別の文面でも条件を拾えるかを確認します。

# FPの暗記は「どこから引くか」で整理する｜必要経費・所得控除・税額控除の3例
どれも金額を差し引く仕組みに見えても、引く段階は同じではありません。制度名を覚える前に、収入・所得・税額のどこを計算しているかを固定します。

ここでは税務申告の個別判断ではなく、学習上の分類方法を扱います。金額例は計算の段階を見分けるための仮定で、実際に適用できる控除額や納税額を算出したものではありません。

## 三つの言葉を計算の順に置く
| 項目 | 差し引く段階 | 何を計算するか | 例 |
| 必要経費 | 事業の総収入金額などから | 所得金額 | 売上原価など、業務上必要な費用 |
| 所得控除 | 所得の金額から | 課税される所得 | 基礎控除、社会保険料控除等 |
| 税額控除 | 算出した所得税額から | 控除後の税額 | 配当控除、住宅借入金等特別控除等 |

整理の根拠は国税庁の[事業所得](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1350.htm)、[所得控除](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1100.htm)、[税額控除](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1200.htm)です。個々の控除には対象・限度・計算等の要件があり、名前を知っているだけで適用できるわけではありません。

## 小ケースA：事業の収入と必要経費
総収入100万円、当該事業の必要経費20万円だけがあると仮定します。他の調整は今回の例には含めません。この段階の所得金額は100−20＝80万円です。

ここで聞きたいのは「80万円にどんな税率を掛けるか」ではなく、「20万円はどの段階で差し引いたか」です。答えは、事業所得を求めるために収入から差し引いた必要経費です。給与の収入を同じ方法で計算する例として一般化しないでください。

## 小ケースBとC：名前より計算位置を見る
| 仮の資料に書かれた内容 | 分類 | その理由 |
| 課税所得を求める前に、適用要件を満たした控除を所得から差し引く | 所得控除 | 所得を計算の土台にしている |
| 所得税額を計算した後に、要件を満たした控除を税額から差し引く | 税額控除 | 税額へ直接作用している |

B・Cでは控除額を仮に設定していません。実際の要件と控除額を確認せず、架空の数字を「現行制度の金額」に見せないためです。初めは名称を隠して段階から答え、次に代表的な制度を見て段階を説明します。

## 間違ったメモは、足し引きより分類を先に直す
| 学習メモの誤り | 修正する点 |
| 必要経費も所得控除も全部売上から引く | 事業所得を求める段階と、課税所得へ進む段階を分ける |
| 所得控除が同額なら納税額も必ず同額減る | 所得と税額への作用を区別する。実際の税額は条件に基づき計算する |
| 税額控除を受ける条件は確認しなくてよい | 制度ごとの対象・限度・手続きを原資料で確認する |

「引くから同じ」と思った箇所を、「何から引くか」という列へ戻します。これでどの数字を隠して確認すべきかも決まります。

## 3級と2級で、教材に加える問いを変える
3級の学習では、まず制度の目的、基本の対象、用語の対応を確認します。2級を含むより複雑な問題を扱う段階では、条件・特例・複数制度の組み合わせを原資料に沿って比較します。これは復習の組み立て方であり、各級の正式な出題範囲を網羅した一覧ではありません。

| 先に確認するもの | 次に加えるもの |
| 制度名と働く段階 | 誰が、どの年の、どの条件で使うか |
| 代表的な金額や率 | 基準日、上限、例外、計算順 |
| 用語の意味 | 事例の条件を読んで適用の可否を考える |

## 数字には基準と原典を残す

# 行政書士の法律用語を事例から選ぶ｜取消し・無効等確認・不作為の3問
条文の語句を覚えたのに、事例を読むとどの制度か迷う。その場合は名称を増やすより、裁判所にどの結果を求めるのかを一文で整理します。

以下は訴えの定義を区別するための架空の学習例です。実際の事件について訴訟類型や提訴の可否を助言するものではなく、訴訟要件等をすべて満たすと判定した事例でもありません。

## 三つの訴えは、求める結果が異なる
| 訴え | 問題にしているもの | 求める結果 | 根拠 |
| 処分の取消しの訴え | 行政庁の処分 | 処分を取り消すこと | 行政事件訴訟法3条2項 |
| 無効等確認の訴え | 処分・裁決の存否や効力 | その存否・効力の有無を確認すること | 同条4項 |
| 不作為の違法確認の訴え | 法令に基づく申請に対し、相当期間内にすべき処分・裁決をしないこと | その不作為の違法を確認すること | 同条5項 |

この定義は[e-Govの行政事件訴訟法](https://laws.e-gov.go.jp/law/337AC0000000139)第3条に基づきます。「違法という言葉があるから全部取消し」と選ばず、何を取り消し、何を確認するかを分けます。

## 三つの相談文を、定義へ対応させる
| 自作ケース | 定義に対応する訴え | 判断の核 |
| A：既にされた処分の取消しを求めている | 処分の取消しの訴え | 求める結果が処分の取消し |
| B：処分の効力がないことの確認を求めている | 無効等確認の訴え | 求める結果が効力の有無の確認 |
| C：法令に基づく申請について、相当期間内にすべき処分がされないことの違法確認を求めている | 不作為の違法確認の訴え | 申請に対して何もしないことの違法確認 |

まず訴えの列だけを隠して答え、次は名称を見せて判断の核を説明します。Aの処分が本当に違法か、Bの効力がないか、Cの相当期間を過ぎているかを、この短い文だけで実案件として確定する練習ではありません。

## 「許可を出すよう命じてほしい」は別に考える
Cの文を「不作為の違法を確認してほしい」から「一定の処分をすべき旨を命じてほしい」へ変えたら、求める結果が変わります。同条6項の義務付けの訴えなどの定義・要件へ戻って確認すべき場面です。

単に「行政庁が何もしていない」という共通点で同じ名称を答え続けず、結論の動詞が「確認する」か「命ずる」かも読みます。具体的に何を提起できるかは、それぞれの法定要件を別途確認します。

## 五つの比較軸は、他の制度にも使える
| 軸 | 読むべきこと |
| 主体 | 誰が利用・主張できるか |
| 対象 | 何の行為や関係に対する制度か |
| 要件 | 成立や利用に必要な事実は何か |
| 効果 | 何が変わるか、誰へどの範囲で及ぶか |
| 期間・手続 | いつまでに、どこへ、どう行うか |

語句の意味を問う段階と、要件に事実を当てはめる段階は分けます。条文番号だけ覚えたら終わりにせず、問題文でどの条件を拾ったか戻れるようにします。

## 短い説明を作る練習
Cについて「法令に基づく申請に対し、相当期間処分をしないことの違法確認を求めるため、不作為の違法確認の訴えの定義に対応する」とまとめます。文章の核は申請、相当期間、不作為、違法確認です。

これは定義を説明する自作の答案例で、公式試験の採点基準や字数への適合を保証するものではありません。実際の記述問題では、問われた範囲と指定された形式で回答を組み立てます。

# 宅建の数字を条件ごと覚える｜媒介契約3種類を4つの軸で比較する
5日、7日、1週間、2週間だけを別々に覚えると、登録期限と報告頻度が混ざります。同じ表に契約の種類、他社への依頼、自己発見取引、登録、報告を置いて確認します。

以下は売買の媒介契約を学習するための整理です。個別の契約を選ぶ助言ではありません。自作の設問と、法令・公式説明に基づく制度の情報を分けて示します。

## 三種類を、同じ条件で並べる
| 媒介契約 | 複数の業者へ依頼 | 自己発見取引 | レインズ登録 | 業務報告 |
| 一般媒介 | できる | できる | 法定の登録義務なし | 法定の定期報告義務なし |
| 専任媒介 | できない | できる | 契約締結日の翌日から7日以内 | 2週間に1回以上 |
| 専属専任媒介 | できない | できない | 契約締結日の翌日から5日以内 | 1週間に1回以上 |

登録の日数では、不動産会社の休業日とレインズ休止日を除きます。一般媒介でも登録や報告を求めることは可能です。「法定義務がない」と「してはいけない」を混同しないでください。根拠は[東日本レインズの媒介契約制度](https://www.reins.or.jp/contract/)です。

## 自作3問：数字だけを答えない
| 問い | 回答 | 表へ戻る位置 |
| 専任媒介で、依頼者が自分で買い手を見つける取引は可能か | 可能 | 専任媒介×自己発見取引 |
| 専属専任媒介の登録期限は何日以内か | 契約締結日の翌日から5日以内。除外される日を確認する | 専属専任×登録 |
| 一般媒介に法定の定期報告義務がないなら、報告を求められないのか | 求めることは可能 | 一般媒介×報告と注記 |

答えを隠すときは、契約名と問いの列を残します。5日だけ隠して何の期限か分からなくするより、条件と数字を一緒に確認できます。

## 登録期限と報告頻度を入れ替えない
「専任だから2週間以内に登録」と書いたら、制度名は合っていても列が違います。2週間は業務報告の頻度で、登録は7日以内です。誤答記録は「専任／登録と報告の列を混同」と残します。

逆に「一般だから登録禁止」とした場合は、義務と可能性の取り違えです。復習する場所は数字ではなく、表の注記です。同じ問題をすぐ繰り返すだけでなく、別の条件から説明してみます。

## 原則と例外は、欄を分けて残す
| 原則側で確認するもの | 追加条件として見るもの |
| 通常の取引・主体 | 売主、媒介、代理などの場面の違い |
| 基本の期限や上限 | 特約や手続き、除外日の扱い |
| 一般的な効果 | 第三者や対抗関係など、問題が付け加えた条件 |

今回の日数でも、休業日の扱いを消すと正しい期限計算へつながりません。具体的な営業日カレンダーがないのに、任意の日付から到達日を確定させることもしません。

## 契約の選択と、試験での分類は別
「複数社へ依頼したい」という一条件なら表から一般媒介に対応すると読めます。しかし、実際の契約を選ぶときは、依頼内容や契約条項の説明が必要です。この表だけで現実の選択を推奨するものではありません。

学習では、問いが登録の義務・期限・報告のどれかを特定してから答えます。名称と数字を暗唱できたかに加えて、なぜ別の列の数字ではないかまで言えることを確認してください。

# 社労士の期間を起算点から覚える｜定時決定・随時改定・育休終了時改定を比べる
同じ「3か月」でも、どの月から数えるかは制度で異なります。対象月だけでなく、きっかけと適用開始を横に並べると、数字を移し替える誤りを見つけられます。

ここでは標準報酬月額の見直しを学習例にします。各制度のすべての要件や実務処理を網羅せず、実際の届出は日本年金機構の案内で条件を確認する前提です。下の具体月は計算の読み方を説明する仮例です。

## まず、三つの開始条件をそろえて読む
| 制度 | きっかけ | 見る報酬の月 | 新しい標準報酬の適用 |
| 定時決定 | 毎年の定例の決定 | 原則4・5・6月 | 9月から翌年8月まで。途中の改定等は別途確認 |
| 随時改定 | 固定的賃金の変動と所定の要件 | 変動後の報酬を初めて受けた月から継続3か月 | その最初の月から4か月目 |
| 育児休業等終了時改定 | 終了日に3歳未満の子を養育する被保険者の申出等 | 終了日の翌日が属する月以後3か月 | 4か月目から |

根拠は日本年金機構の[標準報酬月額の説明](https://www.nenkin.go.jp/service/kounen/hokenryo/hoshu/20150515-01.html)、[随時改定](https://www.nenkin.go.jp/service/kounen/hokenryo/hoshu/20150515-02.html)、[育児休業等終了時の変更届](https://www.nenkin.go.jp/service/kounen/hokenryo/menjo/ikuji-menjo/20150407.html)です。

育休終了時の起点を、単純な「終了の翌月」と覚えないでください。翌日が属する月なので、月途中に終了した場合は同じ月から数えます。

## 同じ8月でも、何が起きた月かを指定する
| ケース | 起点の確認 | 対象月 | 適用月の例 |
| A：固定的賃金の変動後の報酬を初めて8月に受け、随時改定の他の要件も満たす | 初めて受けた月は8月 | 8・9・10月 | 11月 |
| B：育休が8月15日に終了し、申出等の要件を満たす | 翌日は8月16日で、属する月は8月 | 8・9・10月 | 11月 |
| C：育休が8月31日に終了し、申出等の要件を満たす | 翌日は9月1日で、属する月は9月 | 9・10・11月 | 12月 |

BとCは、どちらも「8月に育休終了」ですが起点が異なります。日付を省いて同じ答えを選ぶと、一か月ずれます。この表は対象月を読む練習であり、報酬額や日数がない実案件の改定可否を判定したものではありません。

## 日数や等級差の条件まで消さない
随時改定には、固定的賃金の変動、原則2等級以上の差、各月の支払基礎日数等の条件があります。育児休業等終了時改定は同じ要件ではなく、1等級以上の差や、対象期間に基礎日数の要件を満たす月があることなどを確認します。短時間労働者等の扱いも公式案内で分けて確認します。

「3か月過ぎたので必ず改定」と短く書くのではなく、「対象月を特定した後、日数・差・申出などを確認する」と順序を残します。

## 三問を、理由付きで答える
| 問い | 回答の核 |
| 毎年4〜6月を基に9月からの標準報酬を決めるのは | 定時決定 |
| Bを9〜11月と答えた誤りはどこか | 終了の翌月で数えた。翌日8月16日が属する8月が起点 |
| AとBが同じ対象月なら制度の条件も同じか | 同じではない。起点と等級差・日数等の要件を各制度で確認する |

最初は制度名を隠し、次に対象月を隠して起点から計算します。表全体を隠すのではなく、理由を説明する条件は読める状態にします。

## 成分表に、出典の章とページを付ける

## 分類の表は、成分の表と別に残す
| 一般用医薬品の区分 | 販売を担当できる専門家の基本整理 | 情報提供の学習で確認すること |
