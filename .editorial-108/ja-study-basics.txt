# iPhoneで赤シート学習を始める｜最初の1枚を「答えられる問題」にする
教材を撮影して語句を隠したら、すぐ勉強が始められます。ただし、隠す場所が多いほどよいわけではありません。最初は一枚の教材で、問い・答え・答え合わせの戻り先を整えましょう。

この記事では、説明用に作成した「水の状態と循環」の小さな教材を使います。アプリの自動検出結果や、実際の学習効果を測った記録ではありません。

## 元の教材を、答えと説明の組にする
| 番号 | 用語 | 元の説明 |
| R1 | 蒸発 | 液体の水が水蒸気へ変わること。 |
| R2 | 凝結 | 水蒸気が液体の水へ変わること。小さな水滴は雲をつくる。 |
| R3 | 降水 | 雨や雪などとして、水が雲から落ちてくること。 |

用語を三つ覚えるだけでなく、「状態が変わる」と「落ちてくる」の違いを説明できることが今回の目標です。説明の根拠は[USGSの凝結](https://www.usgs.gov/water-science-school/science/condensation-and-water-cycle)と[降水の資料](https://www.usgs.gov/water-science-school/science/precipitation-and-water-cycle)です。

## 適切なマスクと、隠しすぎを比べる
| 隠し方 | 見えるもの | 学習時に起きること |
| 用語だけ隠す | 元の説明と番号 | 説明を読んで用語を答えられる |
| 用語と説明を全部隠す | R1、R2、R3だけ | 何を問われたか分からない |
| 用語を隠すが題名に同じ語が残る | 説明と答えの手掛かり | 思い出さなくても探して答えられる |

よいマスクは、答えを隠しながら問題を残します。写真の見出し、図の凡例、別の行に同じ答えがないかまで確認してください。毎回同じ位置を覚えて答えてしまう場合には、問いの順序を変えることも検討します。

## まず、このページで3問試す
{{QUIZ:WATER-3}}

これは記事内の練習です。アプリ画面ではありません。答えを見る前に声に出すか短く書き、答えを開いてから元の説明と照らし合わせます。「凝結」を「降水」と答えたときは、R2とR3で何が起きるかをもう一度説明してみてください。

## 手元の教材をAI赤シートへ取り込む
最初は明るく、影や傾きが少なく、文字が読める一枚を用意します。カメラ、写真、PDFのいずれかから取り込み、通常モードで提案されたマスクを確認します。不要な部分を外し、必要な答えが隠れるよう調整して保存します。

## 間違いを、記憶の問題と教材の問題に分ける
| 結果 | 次にすること |
| 答えを思い出せず、見れば理解できる | 元の説明を確認し、間を空けてもう一度答える |
| 二つの用語を取り違える | 同じ表で違いを一文にする |
| 答えを見ても意味が分からない | 読む・図を説明する・問題を解く段階へ戻る |
| 写真が不鮮明、マスクがずれている | 撮り直しや取り込み方法の見直しを先にする |

写真が読めない問題を、復習回数で解決しようとしないことが大切です。逆に、説明は読めるのに思い出せなかった箇所は、次の短い確認に残します。

## 一枚を完成させてから、増やす
無料保存枠は最初に3枚、初回の学習セッション完了後に10枚へ広がります。取り込み中の下書きや予約枠も空き枠に影響するため、最初から大量に取り込まず、一枚を保存・学習・再確認まで使う方が状況を把握しやすくなります。

一枚の完成基準は「保存できた」だけではありません。答えられる問いがあり、誤答後に説明へ戻れ、次回どこを確認するか決まっていることです。複数ページの整理は学校プリントや資格学習のガイドで扱います。

# 学校プリントをスマホで復習する｜6枚を「覚える・解く・戻る」に分ける
プリントを全部撮ることと、復習に使える状態にすることは別です。答えるためのページ、問題を解くページ、間違えたときの解説を分けると、撮影後の使い道が決まります。

以下のP1〜P6は整理方法を説明する仮のプリントです。学校の実際の配布物や成績データではありません。

## 取り込む前に、6枚の役割を決める
| プリント | 内容 | 今回の扱い |
| P1 | 基本用語の説明 | 回答する語句を決めて取り込む |
| P2 | 器官や過程の図 | 図を残し、名称と働きを問う |
| P3 | 二つの制度の比較 | 違いを答えるページとして取り込む |
| P4 | 計算や記述の演習 | 紙や元の形式で解く。撮影だけで代替しない |
| P5 | P4の解説 | 間違いから戻れる参照資料として保持する |
| P6 | P1のコピー | 重複した学習ページは増やさない |

今回のスマホ用候補はP1・P2・P3と、戻り先のP5です。P4を使わないのではなく、解き方が違うため役割を分けています。すべてを一問一答へ変える必要はありません。

## 撮影より先に、戻れる名前を付ける
| 元の名前 | 復習で使う名前の例 |
| 写真48 | 理科｜単元3｜基本用語｜P1 |
| 写真49 | 理科｜単元3｜過程の図｜P2 |
| 写真50 | 社会｜制度比較｜P3 |
| 写真52 | 演習4｜解説｜P5 |

長い題名を全て付けることが目的ではありません。科目・単元・原ページが分かれば、誤答から探し直せます。別の日にも同じ授業資料を取り込む場合は、どの版なのかも短く区別します。

{{MEDIA:AS-LIB}}

ライブラリの画面は保存・整理する場所の参考です。表のP1〜P6が実際に並んでいる画面としては扱いません。

## P2の図では、名称と働きを一緒に隠さない
図のラベルを問うときは形や位置関係を残します。働きを問うときは、名称を見せて説明を隠す方法もあります。「同じ図でも何を答えるかが違う」と考えると、ただ多く隠すより問題が明確になります。

通常モードでは提案されたマスクを学習前に確認し、使える編集機能で調整します。赤シート用教材モードには同じ編集機能がないため、編集が必要なら通常モードで取り込み直す選択肢があります。

## 演習の誤答を、スマホのページへ戻す
| 演習での結果 | 戻る場所 | 次の問い |
| 用語が出てこない | P1 | 説明から名称を答える |
| 図の順序を逆にした | P2 | 矢印の向きと起きることを説明する |
| 比較対象の条件を取り違えた | P3 | 同じ条件なら両者は何が違うか |
| 計算手順が分からない | P5とP4 | 解説を確認した後、計算を最初からやり直す |

たとえば「P4の問2で順序を逆にした→P2の中央の矢印」とだけ記録します。翌日にその図を見て説明し、その後でP4の問2をもう一度解けば、教材と演習がつながります。

## 学校から帰った日に全部仕上げなくてもよい
授業当日は科目と原ページが分かるよう保存し、次の短い時間でマスクを確認する、と分けても構いません。ただし確認前の下書きが増え続けると、学習できるページと準備中のページが混ざります。次回の作業を「P2の図だけ確認」と一つ残します。

AI赤シートの取り込み履歴から、一時停止した処理を再開できます。読み取りが悪い写真は先に差し替え、答えが分からない箇所だけを復習対象にします。

プリント整理のゴールは、スマホに全資料がそろうことより「次の誤答がどのページへ戻ればよいか分かること」です。日割りの試験対策へ進む場合は、定期テストのガイドで同じ資料の回し方を決めます。

# PDF教材をiPhoneで復習する｜12ページから必要な4ページを準備する例
PDFのページ数が増えると、取り込みそのものより、何を復習に使うかが曖昧になりがちです。まず用途を分け、必要な範囲のPDFを準備してから取り込みます。

この記事の12ページ文書と処理状態は説明用の仮例です。処理速度や安定性の実測ではありません。

## 元PDFの構成を一度だけ確認する
| 元ページ | 内容 | 今回の選択 |
| 1〜2 | 単元の導入 | 元PDFで読む。必要時の参照先 |
| 3〜4 | 重要語句と比較表 | 自分で答える対象 |
| 5 | 過程の図 | 図を説明する対象 |
| 6 | 演習問題 | 元の形式で解く |
| 7 | 演習の解説 | 誤答から戻る参照先 |
| 8〜12 | 追加資料 | 今回の復習には入れない |

この例では3・4・5・7ページを選びます。6ページを無視するわけではなく、計算・記述を元の形式で練習するためです。図や解説が要らないからではなく、何を答えるために使うかで選びます。

## ページの選択は、取り込み前に行う
AI赤シートはPDF全体を順に取り込みます。必要なページだけ使う場合は、先にPDF編集機能のある別アプリなどで、選んだページだけのPDFを用意してください。AI赤シート内にPDFのページ選択機能がある、と読み替えないでください。

元ページ番号が変わる場合は、教材名やメモに「原PDF p3・4・5・7」を残します。元資料へ戻る番号と、作成した4ページPDF内の番号を混同しないようにします。パスワード保護されたPDFは取り込めません。

## 大量取り込みの前に、保存枠と容量を分けて確認する
PDFの固定20ページ上限はありません。ただし無条件にどんな文書でも処理できるという意味ではなく、無料版の残り保存枠、予約中の枠・下書き、端末の空き容量、文書の大きさに制約があります。

今回の4ページ分を保存できる枠を確認してから開始します。画面に準備済みのページが出た場合は、後続処理の完了を待たず確認できます。完了したページと処理中のページは、別の状態として扱います。

## 中断したら、何が終わっているかを先に見る
| 仮の状態 | 対応 |
| 2ページ確認可能、1ページ処理中、1ページ待機 | 確認可能な2ページを点検。全件完了とは数えない |
| 取り込みを一時停止した | 履歴から対象の取り込みを選んで再開 |
| 特定ページの読み取りが悪い | 元PDFの文字と画像を確認し、必要なら元資料側を直す |
| 下書きが多く空き枠が少ない | 残す下書きと不要なものを整理してから続ける |

これは状態を読む練習用の表で、今回実行したログではありません。待っているだけなのか、ユーザー操作で停止したのか、入力の不鮮明さなのかを分けると、同じPDFの取り込みを無闇に増やさずに済みます。

## 比較表と図で、隠す場所を変える
3〜4ページの比較表では列名・比較条件を残します。5ページの図では、矢印や位置を消しすぎず、名称または働きのどちらを問うかを決めます。7ページの解説は、すべて暗記問題にせず、誤答を確認する戻り先として使えます。

{{MEDIA:AS-LEARN}}

画面は学習表示の参考で、仮の4ページPDFを処理した結果ではありません。マスクを表示した状態と解除した状態で、元の条件まで読めるかを確認してください。

## 一度だけの保存確認と、次の復習
取り込み後は元ページとの対応、欠けた文字、図の向き、マスク位置を確認します。学習中に答えが怪しかった項目は、原PDFの該当箇所へ戻り、その後で同じ問題を答え直します。

# 赤シートと暗記カードを同じ教材で比較する｜手掛かりを残すか、問いを独立させるか
赤シートと暗記カードの違いは、紙かスマホかだけではありません。元のページの文脈を残すか、各問題を単独で成立させるかが違います。同じ6項目を両方にすると、使い分けが見えます。

ここでは外部の学習成績を比較せず、本文用に作った水循環教材を使います。効果や所要時間の優劣を実測した記事ではありません。

## 比較に使う6つの学習項目
| 用語 | 確認する内容 |
| 蒸発 | 液体の水が水蒸気になる |
| 凝結 | 水蒸気が液体の水になる |
| 降水 | 水が雨や雪などで雲から落ちる |
| 浸透 | 地表の水が地中へ入る |
| 地表流 | 地面の表面を水が流れる |
| 蒸散 | 植物を通って水が水蒸気として大気へ出る |

用語の基本は[USGSの水循環資料](https://www.usgs.gov/water-science-school/water-cycle)に基づきます。以下はこれを復習へ変える編集例です。

## 赤シートなら、ページを問題の一部にする
説明の左にある用語を隠し、説明と全体の位置関係は残します。凝結を答えるときも、近くに蒸発や降水が並んでいるため、違いを比較しやすい構成です。

| 赤シートで見せる問い | 隠す答え |
| 液体の水→水蒸気 | 蒸発 |
| 水蒸気→液体の水 | 凝結 |
| 雲から雨や雪として落ちる | 降水 |
| 地表から地中へ入る | 浸透 |
| 地面の表面を流れる | 地表流 |
| 植物を通って大気へ出る | 蒸散 |

ただし、毎回同じ順で見ると「2行目だから凝結」と答えることがあります。名称を答えた後に、なぜ他の用語でないかを一言付けて確認します。

## 暗記カードなら、1枚だけでも答えられる問いにする
カードには周りのページがありません。「水が移動する現象は？」では複数の答えがあり曖昧です。方向と状態を問いに入れます。

| カードの表 | 裏 |
| 液体の水が気体の水になる過程は？ | 蒸発 |
| 水蒸気が液体の水になる過程は？ | 凝結 |
| 雨や雪などが雲から落ちることは？ | 降水 |
| 地表の水が地中へ入ることは？ | 浸透 |
| 地中ではなく地面の表面を水が流れるのは？ | 地表流 |
| 植物を通って水が水蒸気として大気へ出るのは？ | 蒸散 |

これはカード用の質問文です。AI赤シートに暗記カード作成機能があると説明しているわけではありません。実際にカードを作るなら、紙や対応する別の道具を使います。

## 正解数だけでなく、失敗の理由を見る
| つまずき | 赤シートでの見直し | カードでの見直し |
| 同じ位置でしか答えられない | 順を変える、隣の用語との違いを説明 | 順番を変えて単独で質問 |
| 問題の意味が曖昧 | 残した文脈が足りるか確認 | 問いに方向や対象を追加 |
| 凝結と降水が混ざる | 二つの説明を同時に比較 | 裏に違いを短く添える |
| 答えを見ても理解できない | 元の説明や図へ戻る | 元資料を示して読み直す |

元の図表を見ながら関係を確認したい場面では、ページを残す方式が使いやすいでしょう。単独の質問を順序に依存せず確認したいときは、独立した問いを作ります。どちらも、分からない意味まで隠せば解決するわけではありません。

# 社会人の資格勉強をスマホで続ける｜平日10分と週末の演習をつなぐ
短い空き時間で知識を確認することと、試験の問題を解けることは同じではありません。通勤中の回想と、机での演習を往復できるよう、復習の行き先を決めます。

平日10分・週末30分という時間は、計画を考えるための仮例です。合格に十分な総勉強時間や、誰にでも最適な間隔を示す数字ではありません。

## 同じ勉強を小分けにするのではなく、役割を分ける
| 作業 | 用意するもの | 短時間での使い方 |
| 読む | 現年度の教材と解説 | 分からない制度や概念を理解する |
| 思い出す | 重要な比較表や用語ページ | 答えを隠して名称・条件を言う |
| 解く | 過去問や演習問題 | 主体、時点、条件を読んで判断する |
| 戻る | 誤答と元ページの対応 | なぜ間違えたか確認する |

教材を撮って答えるだけで、記述・計算・事例問題をすべて代替しません。机で間違えた条件を、次の移動時間の短い確認へ渡します。

## 一週間の仮計画
| 日 | 作業 | 次へ渡す記録 |
| 月・10分 | 比較表Aの3項目を答える | 取り違えた条件を一つ |
| 火・10分 | Aの誤答と制度Bを確認 | Bの根拠ページ |
| 水・10分 | Bを別の聞き方で答える | 残る疑問 |
| 木・10分 | AとBを横に比較 | 原則と例外の差 |
| 金・10分 | 今週の不確かな2項目を確認 | 週末に解く問題の番号 |
| 週末・30分の枠 | 実際の問題を解き、解説へ戻る | 翌週に優先する誤答 |

30分で終わらない問題なら、その枠で扱える範囲を選びます。時間だけを守り、理由が分からないまま終えることが目的ではありません。

## 水曜日にできなかったら、木曜日を倍にしない
水曜に未実施、木曜の時点で「Aは答えられるがBの起算点が不明」と分かったとします。木曜はBの起算点を読み直してから答え、金曜にAとBを短く比較します。予定していた追加語句は翌週へ移し、週末の問題を解く時間は残します。

未実施の全量を翌日に積むより、次の判断を妨げているものを先に扱う調整です。これは計画の例であって、学習効果を測った結果ではありません。

## 誤答を四つに分ける
| 誤答 | 戻り先 | 次の確認 |
| 用語が出ない | 定義のページ | 説明から名称を言う |
| 似た数字を取り違える | 条件付きの比較表 | 主体・起算点・期間をセットで言う |
| 条件の読み落とし | 元の問題文 | 否定や対象者を確かめて解き直す |
| 計算や記述ができない | 解説と問題 | 手順や必要語句を取り出し、実際に書く |

例えば「問12を誤答」とだけ残さず、「問12／起算日を終了日と誤読／教材p28」と記します。翌日の10分は、その一行から始められます。

## 資格ごとに、次に読む場所を変える
| 資格 | 個別記事で扱う例 |
| ITパスポート | SaaS・PaaS・IaaSを、管理する範囲と利用場面で区別 |
| 宅建 | 媒介契約を、依頼・自己発見・登録期限・報告で比較 |
| FP | 必要経費・所得控除・税額控除を、引く段階で区別 |
| 行政書士 | 三つの訴えを、裁判所に求める結果から選択 |
| 社労士 | 標準報酬の見直しを、開始条件と対象月で区別 |
| 登録販売者 | 成分・作用・注意事項を、公式手引きに戻して確認 |

## 教材を、次の短い復習で開ける状態にする
{{MEDIA:AS-LIB}}

AI赤シートでは、手元の写真やPDFを保存し、フォルダ・検索で範囲を選べます。教材名には試験名・年度・論点・原ページが分かる要素を残します。順番、ランダム、弱点優先の使い方も、確認したい内容に合わせます。
