@@ 課本講義-遮罩自我測驗
# 把課本講義照片變成自我測驗：先完成一張能作答也能訂正的複習頁
拍清楚教材只是第一步。要形成自我測驗，還要決定隱藏哪個答案、保留哪些線索，以及答錯後回到哪裡核對。

下方水循環小教材依USGS說明編寫，題目與版面由本文設計。它不是App自動辨識的實測畫面，也不代表考試的完整範圍。

## 從可以核對的原始材料開始
| 編號 | 詞語 | 說明 |
| R1 | 蒸發 | 液態水變成水蒸氣。 |
| R2 | 凝結 | 水蒸氣變成液態水；細小水滴可以形成雲。 |
| R3 | 降水 | 水從雲中落下，例如雨或雪。 |

這頁要分清楚的是狀態變化與從雲中落下。把凝結答成降水時，應比較R2與R3，而不只是再看一次正確詞語。依據：[USGS凝結說明](https://www.usgs.gov/water-science-school/science/condensation-and-water-cycle)、[USGS降水說明](https://www.usgs.gov/water-science-school/science/precipitation-and-water-cycle)。

## 遮住答案，不要連問題一起遮住
| 保留的內容 | 遮住的答案 | 要確認的理解 |
| 液態水變成水蒸氣 | 蒸發 | 狀態變化的名稱 |
| 水蒸氣變成液態水 | 凝結 | 與蒸發方向相反 |
| 水從雲中以雨或雪等形式落下 | 降水 | 形成水滴與落下的差別 |

如果連說明都遮住，就沒有可回答的問題。如果旁邊標題仍出現答案，可能只是找字，而不是回想。請連圖說和頁邊提示一起確認。

## 先回答，再展開答案

## 依照錯誤種類決定下一步
| 觀察 | 下一步 |
| 詞語正確，也能解釋 | 隔一段時間再測，不只立即重複同一詞 |
| 把凝結回答成降水 | 回到R2、R3，說明各自發生什麼變化 |
| 答案仍出現在標題 | 調整遮罩後，再判斷是否真的記住 |
| 原圖文字看不清楚 | 先換圖，不把輸入品質當成記憶錯誤 |
| 展開答案後仍不懂說明 | 回到閱讀或解題，不是繼續增加遮罩 |

第一張合格複習頁不以遮得多為標準，而是有三個能回答的問題，以及從錯誤回到說明的短路徑。App協助重複使用手邊教材，不會替你判定整份考試的所有重點。

@@ 會考學測國考-自己的pdf
# 用自己的PDF與講義準備會考、學測或國考：一週複習安排範例
教材存進手機後，還要決定哪頁用來背、哪頁用來理解、哪頁必須實際作答。把錯誤連回原始說明，避免資料整理完了卻沒有檢驗理解。

六頁教材與七天安排是虛構的教學範例，可依實際課程、考科與準備進度調整；不是官方備考日程，也不是適合每個人的最佳複習間隔。

## 每一頁都有不同的用途
| 頁碼 | 內容 | 用法 |
| P1 | 三個詞語的定義 | 回想關鍵詞 |
| P2 | 一張流程圖 | 解釋箭頭與關係 |
| P3 | 相近概念比較表 | 說出差異 |
| P4 | 練習題 | 按原本題型完整作答 |
| P5 | 詳解 | 找出錯誤原因 |
| P6 | P1的重複掃描 | 不再增加一份相同任務 |

會考、學測教材中的圖表判讀，或國考中的計算與情境題，都不能一律變成辨認遮住的詞語。保留原有作答要求，再決定哪些知識適合用短時間回想補充。

## 讓教材名稱能帶回錯誤來源
「第三單元—流程—P2」比「照片48」更容易定位。標題或備註保留原頁碼、主題與來源；資料夾分類，頁碼則把某個錯題帶回正確說明。

{{MEDIA:AS-LIB}}

圖片是資料庫操作的參考，並非本文虛構的P1到P6教材。沒有將新案例合成到實際App畫面內。

## 第一週，把回想與解題放在一起
| 日期 | 工作 | 留下的紀錄 |
| 第1天 | 閱讀P1到P3，準備少量明確問題 | 原頁碼與不合適的遮罩 |
| 第2天 | 回答P1並解釋P2 | 具體混淆，不只記錯題數 |
| 第3天 | 比較P3，回查前一天錯誤 | 兩個概念不同的理由 |
| 第4天 | 用原格式完成P4 | 每個錯題對應P1到P3或P5 |
| 第5天 | 回到相關說明 | 一句訂正後的解釋 |
| 第6天 | 試另一題相同弱點的題目 | 能否離開原頁運用知識 |
| 第7天 | 確認未解決的地方 | 下一週的小目標清單 |

## 少做一天，不必讓隔天所有工作加倍
假設E1是忘了P1的詞，E2是把P2箭頭方向解釋錯了。E1可用詞語提問確認，E2必須重新說明流程；只打開同一標籤，不能證明關係已理解。

第三天沒做完時，先保留第四天的一次真實解題，再挑最影響解題的兩個錯誤回看。已經穩定的詞可以稍後複查。調整的目的，是讓計畫能執行，而不是把固定天數當成適合所有人的規則。

## 用AI Study Sheet安排可重複的部分
匯入選好的照片或PDF、檢查遮罩後儲存，再以資料夾或搜尋選定學習範圍。依序有助於追蹤過程，隨機可確認是否依賴頁面順序，弱項優先則回到已記錄的困難。選能完成的題數，而不是只選最大的數字。

App的成績不等於掌握整個考科。計算、論述、資料判讀和新題仍要分別練習。一週之後，你應能說明下次看哪頁、為了訂正什麼，以及用哪道題檢查理解。

@@ 學習資料-本機處理-隱私
# 學習資料在哪裡處理：把本機辨識、購買、匯出與備份分開看
「在裝置內處理」不等於「每個操作永遠不連網」。確認教材的隱私範圍，要分別追蹤辨識、儲存、購買和自己主動分享的路徑。

本文根據Toybird Labs的AI Study Sheet隱私政策與使用說明整理，並不是網路流量稽核，也不把離線能使用App視為完全不通信的證據。

## 四條需要分開說明的路徑
| 操作 | 資料 | 官方說明中的範圍 |
| 匯入、辨識、遮罩與學習紀錄 | 教材影像、PDF、辨識文字、遮罩、紀錄 | 在裝置內處理與儲存，不將教材傳至外部AI或開發者伺服器 |
| 購買與回復購買 | App Store購買狀態 | 使用Apple商店與StoreKit，可能與Apple通信 |
| 主動匯出或分享 | 備份檔與圖片 | 由使用者選擇的App或服務接收，適用其規則 |
| 系統或裝置備份 | 備份設定涵蓋的資料 | 取決於iOS與使用者選定的雲端服務，不等同App自動同步 |

原始資料見[官方隱私政策](https://labs.toybird.com/apps/ai-memorize-sheet/privacy.html)及[使用說明](https://labs.toybird.com/apps/ai-memorize-sheet/support.html)。功能有變化時，應重新核對來源，不能只根據一張「離線」圖片判斷。

## 用一張自製教材走過流程
準備只有虛構資料的一頁，例如「示例班級A組；水循環問題」。拍照或選擇本機檔案，檢查App內的辨識、遮罩和儲存。這能確認特定功能是否可用，但一次觀察不能證明所有網路行為。

接著分別確認自己有沒有執行分享、檔案存到哪裡、系統是否設定相關雲端備份。不要用真實姓名、成績單或不應外傳的教材測試。

## 離線測試能支持的結論有限
| 觀察 | 能說明 | 不能直接說明 |
| 離線仍能查看已儲存教材 | 該本機操作當時可用 | 每一項功能都不會連網 |
| 沒有要求開發者帳號 | 目前流程不需要該帳號 | 系統備份或其他服务沒有副本 |
| 分享時選了雲端硬碟 | 使用者決定將檔案交給該服務 | 服務的保留與刪除規則和App相同 |
| 刪除App內的一頁 | 本機頁面被刪除 | 以前匯出的備份或別人收到的檔案也消失 |

判斷範圍不要超過觀察範圍。若要檢驗網路行為本身，必須有相應紀錄與分析，不能從「成功辨識」直接跳到「絕對安全」。

## 分享前先選擇必要內容
假設讲義左上有學生姓名，正文是課堂題目。只需要練習正文時，可先用合法且適當的方式準備不含姓名的副本。自行選擇把原檔送到雲端硬碟或通訊軟體，就跨出了原本的裝置內處理範圍。

匯出前確認收件對象、非必要個資、教材分享權限、儲存位置及後續需管理的副本。這份檢查用於整理自己的操作，不能取代學校或單位的資料規範。

## 備份不等於持續同步
App讓使用者主動匯出備份，不代表會持續自動同步到雲端。換機前依官方說明準備並驗證備份；在新裝置確認資料完整前，不要先刪除唯一原件。先前匯出的檔案，需在各自的位置管理。

有用的結論不是一句「完全不連網」，而是一張清楚的資料路徑表：什麼留在裝置、什麼因購買通信、什麼因自己分享而離開。AI Study Sheet的本機教材處理與使用者主動使用其他服務，應分別描述。

# 在單一Mac螢幕工作：把需要的參考資料留在眼前
主要工作在一個視窗進行時，偶爾查閱的文件不一定需要占半個螢幕。小型參考視圖可以保留必要幾列，讓主工作仍有足夠面積。

請用同一項工作比較配置。下面的規格表和判斷筆記是虛構教材，不是計時後的效率測量。

## 從三個選項完成一段判斷
需要兩週內交付、至少一年保固的零件。價格是任意的示例單位。

| 選項 | 交付 | 示例價格 | 保固 |
| A | 2週 | 120 | 1年 |
| B | 3週 | 100 | 2年 |
| C | 未確認 | 90 | 未確認 |

筆記要指出A符合兩項條件、B超過期限、C必須補問。只留下價格欄會失去判断依據，所以列內容與欄位名稱應一起保留。

## 依兩個視窗的操作頻率選擇
| 工作方式 | 先考慮的配置 | 原因 |
| 不斷編輯原文件與筆記 | 一般視窗並排 | 兩邊都需要操作空間 |
| 以寫筆記為主，偶爾看幾列 | 主視窗加小參考視圖 | 把面積留給主要工作 |
| 理解完整示意圖或密集表格 | 較大的原視窗或分割顯示 | 可讀性與完整脈絡優先 |

macOS提供視窗平鋪及Split View等選擇，操作會隨版本改變，可查閱[Apple視窗說明](https://support.apple.com/guide/mac-help/tile-app-windows-mchlef287e5d/mac)。浮動參考是補充，不必在每種情況取代系統功能。

## 讓小視圖保留關係
開啟原資料與筆記，在Pocket Screen選擇來源視窗，保留相關列和欄位名稱，再回到寫作。不要讓參考蓋住正在輸入的句子或重要按鈕。若必須一直放大才能閱讀，應給來源更多空間，而不是堅持最小視窗。

重點不是把所有東西都置頂，而是持續主工作時，仍看得到判斷所需的部分。

## 區分即時狀態與保留的狀態
需要追蹤現在的資訊時使用即時參考。凍結視圖保留某個時刻，不會自動納入之後的修改。做最後決定前，仍要回到來源確認條件。

一個瀏覽器視窗的示範，不代表所有分頁都能同時獨立即時擷取。請以安裝的公開版本為準，不把未來版本示範當作目前提供的功能。

## 最後的筆記要能回到原表核對
> A符合兩週交付與一年保固。B的保固較長，但不符交期。C需先確認交付與保固，才能列入符合條件的比較。

小視圖協助取用資訊，不保證資料最新或判斷正確。分享螢幕前，另用無敏感內容檢查對方實際收到的畫面。本例展示配置與判斷流程，不主張實測了時間節省率或所有環境的分享排除效果。

游標移動不代表觀眾知道按鈕的重要性。把說明、目標、操作與結果連起來，觀眾才不用猜剛才發生了什麼。

| 時間 | 說什麼 | 做什麼 | 提示 |

## 點負責定位，範圍負責關係
游標回答「哪個按鈕」，範圍回答「哪些列屬於這段說明」。兩者都不能替代清楚可讀的文字與目的。只說一個開關卻強調整頁，可能讓目標更不明確。

Pointer Cue可在Mac提供暫時的游標與範圍強調，操作請依已安裝版本的設定。需要把箭頭留著稍後參照時，繪圖工具解決的是不同需求，不必把暫時提示當成永久標註。

## 操作後，把結果說出來
明確說出兩個最終狀態並停留一下，比「大家可以看到」更具體。同一腳本先不用提示，再使用游標或範圍提示排練，觀察目標和結果是否容易辨識，不是計算效果數量。

## 檢查接收者的畫面
真正的遠端示範應使用安全的練習內容，查看參與者收到的畫面。小字和細線在擷取、傳輸後可能改變。本機產品影片不是接收端畫質的測試紀錄。

影片中操作網站的片段可以說明提示形式，但不是這個虛構通知介面的執行記錄。預發佈影片也不能自動證明正式版所有功能與提供條件。

## 換成下一次真實示範
選一個不含機密的真實任務，寫下前後狀態，挑一處提示確實能增加資訊的位置，再練習操作後的停頓。暫時標記有助於講解時使用Pointer Cue；結果已經明確時，让介面本身說明即可。
