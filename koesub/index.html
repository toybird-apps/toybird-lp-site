WHY KOESUB

仕事の9割が日本語でも、
英語が必要な瞬間がある。

日本を拠点に働く外資系企業の社員や、海外企業と取引するビジネスパーソン。日常業務の大半は日本語でも、海外の上司や同僚との会議、突然の問い合わせ、転職活動など、重要な場面で英語が必要になることがあります。

こうした場面で大きな障壁となるのが、相手の英語を聞き取れないこと。相手の意図を理解できれば、完璧な英語でなくても自分の考えや熱意を伝えることはできます。

外資系企業での20年以上の実務経験をもとに、実際のビジネスシーンでの応答速度と使いやすさを重視して開発されました。

相手を理解することが、
コミュニケーションの
出発点。KoeSubが支援するのは、会議後の記録ではなく、いま交わされている言葉の理解です。
USE CASES

英語がハードルになる、
3つのビジネスシーン。

英語が必要なタイミングは毎日とは限りません。しかし、その会話が仕事やキャリアの重要な判断につながることがあります。

01 / CAREER

転職・キャリアアップ

英語力だけで、キャリアの選択肢を狭めない。

HRとの面談、海外のHiring Managerとの面接、パネルインタビュー。専門性や実績があっても、英語の聞き取りへの不安から挑戦をためらうことがあります。KoeSubは、相手の質問を日本語字幕で理解するための補助として役立ちます。

※面接での利用は、応募先のルールや許可に従ってください。

02 / COLLABORATION

海外チームとの情報交換

資料にない情報を、直接聞きにいく。

海外拠点の成功事例や最新の取り組みは、必ずしも文書化されているとは限りません。担当者との会話が最も効率的でも、英語が心理的な負担になることがあります。KoeSubは情報収集やノウハウ共有をリアルタイム字幕で支援します。

03 / URGENT CALLS

海外マネージャーからの突然の連絡

急なミーティングでも、状況を理解する。

四半期末の数字確認、重要案件のエスカレーション、グローバルチームからの問い合わせ。予告のない英語の呼び出しでも、ショートカットひとつで翻訳を開始し、相手の質問や要求を理解する手助けをします。

REAL-TIME TRANSLATION

完璧な翻訳より、
会話を理解できる速さ。

KoeSubは、翻訳の正確さよりも、会話のスピードについていけることを重視したリアルタイム翻訳ツールです。

翻訳は完璧ではありません。単語の聞き違いや誤訳、細かなニュアンスの取りこぼしが生じることもあります。

v2.2では翻訳精度を改善しました。相手が何を伝えようとしているのか、会話の大まかな内容をその場で理解できることを目指しています。

一語一句の正確さよりも、今の会話を理解することを優先しています。

※重要な数字、固有名詞、契約条件などは、相手に確認してください。

⌥ Option + S 開始・終了

Singlishへの音声認識適応

シンガポールは多くのグローバル企業がAPAC本部を置く拠点です。KoeSubはシンガポール英語の特徴を独自の音響MLで検知し、十分な根拠がありOSが対応する場合は音声認識をen-SGに適応させます。一般英語の認識が基本で、切り替えは保証されるものではありません。

Macの英語音声を字幕に

Zoom、Microsoft Teams、Google Meet、社内トレーニング、動画など、Macで再生される対応英語音声を翻訳します。必要に応じてマイク入力も利用できます。音声収録権限などの設定が必要です。

SCREEN SHARING

自分には字幕を。
共有画面には映さない。

KoeSubの設定で「字幕を画面キャプチャから除外」を有効にすると、自分のMacには日本語字幕を表示したまま、対応する画面共有・画面収録・スクリーンショットには字幕が映らないようにできます。

英語でのプレゼンテーションやデモ、商談でも、相手の発言を字幕で理解しながら、参加者にはプレゼン資料を共有できます。
